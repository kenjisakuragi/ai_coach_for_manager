## 標準的な1日の流れ

### 朝（5分）
1. 起きる
2. `DAILY_CHECKIN.md` のテンプレを開く
3. 5分で記入
4. **私のチャットに貼り付ける**
5. 私からのフィードバックを読む（1-2分）
6. その日の最優先タスクを確認

### 業務中（適宜）
- 緊急のチャンスや課題があれば、いつでも私に相談OK
- 大きな意思決定がありそうなら、迷わず私に壁打ちを依頼

### 夕方〜夜（5分・任意）
- 必要なら夕方のチェックイン
- 今日の達成度の記録

---

## 標準的な1週間の流れ

### 月曜
- 朝のチェックインに加えて
- `WEEKLY_REVIEW.md` を30分かけて記入
- 私のチャットに貼り付け
- 今週の3つの最優先を一緒に確定

### 火〜金曜
- 通常の朝のチェックインのみ
- 月曜に決めた最優先タスクを実行

### 土曜 or 日曜
- 軽めのミニレビュー（10分）
- 来週の頭出し

---

## 標準的な1ヶ月の流れ

### 月初（1日）
- 月の目標を確認（`12_MONTH_PLAN.md`）
- 月の3つの最重要を決める
- 今月の "やめること" を1つ決める

### 第1〜3週
- 通常の日次・週次運用

### 月末（最終週の金曜 or 土曜）
- `MONTHLY_REVIEW.md` を90分かけて記入
- 私のチャットに貼り付け
- 来月の戦略を一緒に練る
- 必要なら12ヶ月計画を修正

### 私からの返答パターン

#### パターンA｜順調な日
```
おはようございます。

今日の3つの最優先、優先順位は適切です。
特に①は午前中の集中時間にやるのがオススメ。
②は短時間でできるので、間に挟むといいです。

体調7/10、調子は悪くないですね。
午後の重要MTGに備えて、午前中はコーヒーで集中ブースト推奨。

今日も頑張りましょう。
```

#### パターンB｜気になる兆候がある日
```
おはようございます。

体調が4/10、気になります。
昨日も6/10だったので、2日連続の低下です。

今日の最優先3つを見直しましょう：
- ①は本当に今日でないとダメですか？
- ②③は明日に回せませんか？

今日は最低限の業務に絞り、
午後は早めに切り上げて休養を取ることをお勧めします。

無理は12ヶ月の達成を遠ざけます。
```

#### パターンC｜数字が悪化している日
```

月：5件 → 火：4件 → 水：3件 → 木：2件 → 金：1件

これは要警戒です。
今日と来週は意識的にアウトリーチを5件×日復活させましょう。

時間がないなら、コンテンツ制作の時間を一時的に減らしてOK。
M3の売上目標¥2Mに向けて、新規申込が最重要です。

今日のアウトリーチ5件、必達でいきましょう。
```

## "三日坊主" を防ぐ仕組み

### 仕組み①｜習慣化トリガー
朝起きて → コーヒーを淹れる → チェックインを書く → Claudeに貼る
（既存習慣の後ろに新習慣を連結）

### 仕組み②｜可視化
Notionにカレンダー作成、毎日の達成を○×で記録。
連続記録が見える化されると続けやすい。

### 仕組み③｜小さなご褒美
- 1週間連続：好きなものを食べる
- 1ヶ月連続：欲しかったものを買う（5万円以内）
- 3ヶ月連続：旅行・記念品

### 仕組み④｜失敗時のリカバリー
- 1日サボった → 自分を責めず、翌日からまた始める
- 連続記録ゼロから再スタートしない（ずっとやり直しになる）
- 「7日中6日やった」を成功とみなす
