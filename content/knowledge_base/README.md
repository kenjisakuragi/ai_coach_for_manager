# 経営者AI活用｜知識ベース

> このディレクトリは、経営者向けClaude Code活用記事を書くための、
> **検証済み事例・引用・データ** の蓄積場所です。
>
> リサーチで取得できた公開情報のみを記録します。創作・推測は含めません。

---

## ナレッジ管理の原則

### ✅ 蓄積する情報
- WebFetchで取得できた公開記事の要約
- 出典URL付きの引用フレーズ
- 公開済みの数字・データ
- 記事化に役立つ視点・切り口

### ❌ 蓄積しない情報
- 検証できていない伝聞
- 創作・推測の引用
- 非公開の事業情報
- 関係者から共有された機密

## 知識を増やす運用

### 桜木さんが新しい記事や動画を見つけたら
URL を私（Claude）に共有 → 私が WebFetch → 内容を `knowledge_base/` に追記。

### 私が記事を書く時
このディレクトリの知識を引用元として使い、出典を必ず明記。

### 蓄積方針
- 月3-5件、新しい知識を追加
- 半年で50件以上の事例ライブラリへ
- 1年で「日本の経営者AI活用ライブラリ」として最大規模を目指す
