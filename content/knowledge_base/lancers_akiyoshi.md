### 「秋吉」システム

秋好さんが Claude Code で構築した経営者向けシステム。Slack とメールが唯一のインターフェース。

#### 朝6:30〜7:00 の30分フロー
- 6:30〜6:31：今日のブリーフィング確認
- 6:31〜6:45：昨日の重要シグナル確認（社員200人の会議から抽出）
- 6:45〜7:00：戦略アップデート確認（KPI連動アラート、赤/黄/緑）

#### 5つのスキル
1. **経営コンテキスト**：ミッション・3か年計画・今期方針・CEOの考え方（月1更新）
2. **会議スキル**：会議のA/B/Cランク、頻度、参加者、ゴール
3. **会議トラッカー**：各会議に60点等の点数と理由、3週間前からのストーリー追跡
4. **重要シグナル抽出**：200人社員の会議・Slack・Docs から社長視点の重要情報を15件程度抽出
5. **戦略アップデート**：事業部別KPIと現場行動ログを照合、赤/黄/緑信号でアラート

#### マネージャー向け版
- 営業の新規 vs 既存の時間配分を社員1人ずつ可視化
- 「Aさんは新規5%」のようなファクトで現実的なマネジメント

### 中小企業オーナーへの翻訳ポイント

- 「秋吉」をそのまま真似る必要はないが、**設計思想は社員5人規模でも応用可能**
- 朝のブリーフィング小規模版・重要シグナル小規模版・戦略アップデート小規模版で月30時間削減
