# note記事｜立ち上げ期（M1-M2）の3本

> AI駆動経営ラボの立ち上げ期に、最初に公開する3本のnote記事です。
> 事例ゼロでも信頼形成・SEO・読者育成ができる構成にしてあります。

---

## 公開順序の推奨

### 第1週｜記事①：自己紹介
**ファイル**：`01_self_introduction.md`
**タイトル**：「東大AI研究室から、私が『経営者の伴走者』になるまで」

→ まずブランド・人物像を立てる。
→ プロフィール記事として固定表示。

### 第2週｜記事②：30時間問題の分析
**ファイル**：`02_30hour_problem.md`
**タイトル**：「経営者から月30時間を奪う"雑務"の正体｜業種別データで分析した」

→ 痛みの言語化。
→ SEOキーワード「経営者 業務効率化」「中小企業 AI」を狙う。
→ もっとも拡散しやすい記事タイプ。

### 第3週｜記事③：Claude Code 入門
**ファイル**：`03_claude_code_howto.md`
**タイトル**：「経営者がClaude Codeで月10時間取り戻す｜画像付き5ステップ完全ガイド」

→ 即実用記事。
→ SEOキーワード「Claude Code 使い方」を独占的に狙える（競合少）。
→ 経営者の "やってみた" 体験を促す。

## 公開時のチェックリスト

note公開前に：

### ✅ コンテンツ
- [ ] 各リンク（Calendly URL、LP URL等）を実際のURLに差し替え
- [ ] 仮名（X-社、Y-社等）が一貫しているか
- [ ] 数字に矛盾がないか
- [ ] 誇大表現になっていないか

### ✅ SEO
- [ ] タイトルにキーワードが入っているか
- [ ] H2見出しに関連キーワード
- [ ] メタディスクリプション設定（noteは "ハッシュタグ" で代用）

### ✅ ハッシュタグ（noteの場合）
- 記事①：`#自己紹介` `#AIコンサル` `#経営者` `#東京大学`
- 記事②：`#経営者` `#業務効率化` `#AI活用` `#中小企業`
- 記事③：`#ClaudeCode` `#AI活用` `#経営者` `#使い方`

### ✅ 画像
- アイキャッチ画像（1200×630推奨）
- 中盤の図解 1-2枚

### ✅ 公開後
- [ ] X で告知（記事URL＋3行サマリ）
- [ ] LinkedIn で告知（やや硬めの文体で）
- [ ] メルマガで配信（読者がいれば）
- [ ] 既存知人に個別共有（5-10名）

## 編集してOKな箇所、編集すべき箇所

### 必ず編集すべき
- リンクURL（Calendly、LP、X、ココナラ等）
- 連絡先メールアドレス
- 仮名 X-社／Y-社 の整合性確認

### 編集してOK
- 文体の調整（より柔らかく、より硬く）
- 業種事例の追加・差し替え
- 写真・画像の追加

### 編集しない方がいい
- ストーリー構成（現状が最も読まれる構造）
- 数字（裏付けがあるものは変えない）
- SEO観点で配置されたキーワード
