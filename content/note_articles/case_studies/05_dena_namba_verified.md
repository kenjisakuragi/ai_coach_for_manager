# Claude Code経営活用事例｜DeNA南場会長の場合

このシリーズでは、有名経営者の公開発言を題材に、**中小企業のオーナーが Claude Code を経営にどう取り入れるべきか** を読み解きます。

第3回は、DeNA 代表取締役会長の南場智子さんです。

DeNA は、ゲーム・エンタメ・ヘルスケア・スポーツなど多角的な事業を展開する東証プライム上場企業です。その会長が、2025年に DeNA 公式 YouTube チャンネル「事業家の DNA」で、AI 戦略について約 30 分間、踏み込んで語りました。

普通、上場企業の会長は「我が社の AI 活用は順調です」程度の発言で終わります。ところが南場さんは、**プロジェクトによっては 95% を AI がやっている**、**社員として AI を登録している**、**経営者は人を先に動かさないとダメだ**、と実装の内側まで踏み込みました。

しかも南場さんは、AI ツールとして **Claude（オパス 4.5、クロード 4.5）** を具体的に名指ししています。中小企業のオーナーにとって、最も参考になる発言の一つです。

本記事では、南場さんの発言を 4 つの論点に整理します。最後に、私（桜木）が経営者の方に伝えていることをお話しします。

---

## 論点1：「20倍の生産性」は、本当に出るのか

南場さんは、動画の冒頭でこう述べています。

> 「プロジェクトによっては 5% が人で 95% が AI である。20 倍の生産性を手にした」

20 倍。

正直、最初に聞いた時は、私も「言い過ぎでは」と思いました。

ところが南場さんは、続いてこう言います。

> 「特にクロード 4.5、オパス 4.5 が出てですね、去年の 11 月ですか、そこからかな大幅に、行動確悟が減った」

クロード 4.5、オパス 4.5 というのは、AI 大手 Anthropic 社が提供する Claude シリーズの最新版（当時）です。エンジニアの間で「コードを書くという仕事が、ほぼほぼ激減した」状態が、2024 年末から本格化したわけです。

つまり、20 倍は理論値ではなく、**現場で起きている実測値** だということです。

### 業務別の効率化数値

南場さんは具体的な数字も挙げています。

> 「ホーム業務は 90% 効率改善。QA は半分の個数で同じことができる。ポコちゃん（Pococha）の配信審査は 60% 削減」

ホーム業務、QA、配信審査という、それぞれ別系統の業務で、軒並み 50〜90% の効率化が起きています。

ここで、中小企業のオーナーが受け取るべきメッセージは、こうです。

**業務の種類を問わず、適切に AI を入れれば、半分から 1/10 の工数になる。**

これは私の経験でも符合します。議事録、リサーチ、メール下書き、提案書、SNS 投稿。どれも 5〜20 倍の効率化が起こります。

DeNA という大企業の話に見えますが、効率化の比率自体は、中小企業でも変わりません。

## 論点2：AI は「サポート」から「スタッフ」になった

南場さんの発言で、いちばん本質的なのが、ここです。

> 「AI エージェントが進化しましたね。AI がサポートツールからスタッフになった」

「サポートツール」と「スタッフ」。

この違いを、中小企業のオーナーに伝わる言葉で説明します。

サポートツールは、Excel や検索エンジンと同じです。人間が「やってくれ」と頼んだ瞬間だけ動き、終わったら止まります。

スタッフは違います。スタッフは、**朝出社して、自分のタスクを把握して、終わるまで自走します**。困ったら相談してきます。終わったら報告してきます。

南場さんは、これを実装している事例を語ります。

### DeNA 社内の「レモン君」

> 「DNA の IT 本部がですね、オープンクロー（Open Claude）を、社員として登録してなんかこうトレーニングしてる」
>
> 「私はレモン君とスラックでコミュニケーションして、仕事を毎日進めています」

「レモン君」。

DeNA 社内で、Claude をベースにした AI を「社員として登録」して、Slack で会話しているわけです。

南場さんは、レモン君の特徴をこう述べます。

> 「やっぱり 1 回言ったことはずっとやってくれるし、大事なことはやり終わるまでずっとリマインドし続けてくれる」
>
> 「グループチャットの Slack のグループチャットに入れておくとですね、その話の内容を聞いて、レモン君がそれ私きますとかって言って仕事を受けてくれたり」

ここが、サポートツールとスタッフの決定的な違いです。

レモン君は、Slack のグループに入れておくと、会議の内容を聞いて、自分から「それ、私やります」と手を挙げる。一度頼んだ仕事は、ずっと覚えていて、リマインドしてくれる。

これは、**月給ゼロのスタッフを 1 人雇っているのと、ほぼ同じ** ということです。

### 中小企業でも、これは可能か

ここで、中小企業のオーナーが思うことは、こうかもしれません。

「DeNA だからできるんでしょ。うちには IT 本部もないし、エンジニアもいない」

ところが、これが Claude Code を選ぶ理由になります。

Claude Code は、もともとプログラマー向けに作られましたが、操作はチャット形式です。「議事録を書いて」「メールの下書きを作って」と日本語で頼めば、動きます。

一度教えた指示は、CLAUDE.md（クロードに教える取扱説明書）というファイルに書き込んでおけば、ずっと覚えてくれます。

つまり、中小企業のオーナーでも、**自分専用のレモン君** を立ち上げることが、技術的には可能です。

ただし、立ち上げに少しコツがあります。これは後述します。

## 論点3：人材は「浮いてこない」。社長が先に動かす

南場さんの発言で、私が最も衝撃を受けたのは、ここです。

> 「同じ作業するのに楽になった分、仕事を詰め込むんですよ」
>
> 「日本人みんなそうだと思うけれども、同じタスクをするのが、高数が少なくて済むようになると、余った時間でやれたくてもできなかったことを自分でどんどん詰め込んでいく」

つまり、AI で業務効率化が進んでも、社員は「楽になりました、空き時間ができました」とは言わない。**勝手に新しい仕事を詰め込んで、結局忙しいまま** なのです。

これは、私のクライアントである経営者でも、同じことが起きます。「AI で 30 時間浮いたはずなのに、結局忙しい」。なぜか。空いた時間に、自分で新しい雑務を詰め込んでしまうからです。

南場さんの解決策は、こうです。

> 「もう先に動かすということですね。人が浮いてきましたなんて、誰も自ら行ってこないです」
>
> 「もうバサっと先に動かす。ある程度乱暴なリーダーシップが重要なんだと思いますね」

「乱暴なリーダーシップ」。

社員に「空いたら新規事業に異動して」と任せても、人は動きません。社長が「来週から、君は新規事業担当な」と先に決めて、動かす。これが乱暴だが、必要な決断だと言うわけです。

### 中小企業のオーナーは、自分自身に「乱暴」になる

中小企業のオーナーの場合、「動かす対象」は、ほぼ自分自身です。

Claude Code を導入すると、月 30 時間が浮きます。ところが、空いた時間に、いつもどおりの雑用を詰め込んでしまう。これでは意味がありません。

対策は、**空いた時間の使い道を、先にカレンダーに書いてしまう** ことです。

たとえば、こう書きます。

「水曜日の朝 9 時〜11 時：新規開拓のリサーチと電話」「金曜日の午後 14 時〜16 時：戦略を考える時間」「毎朝 7 時〜8 時：業界ニュース読み込みと所感メモ」

カレンダーに先に入れてしまえば、その時間は他のことに使えません。

これが、自分に対する「乱暴なリーダーシップ」です。

## 論点4：「まるま×AI」の、まるまが勝負

南場さんは、新規事業の戦略について、こう述べています。

> 「LLM プレイヤーが、思ったより無慈悲だ」
>
> 「汎用モデルの適用範囲が広がってその速度も極めて早くて、中途半端な専門性では一撃を食らう」

LLM プレイヤーというのは、Anthropic、OpenAI、Google など、AI 大手のことです。彼らが提供する汎用 AI（ChatGPT や Claude）が、毎月のように能力を上げているため、**中途半端な専門性のスタートアップは、一撃で陥落する** という意味です。

ところが、南場さんはこう続けます。

> 「まるま×AI のまるまの部分、すごい重要ですね」
>
> 「深いドメイン知識とか、そのドメインのプレイヤーじゃないと持つことができないようなデータ……簡単に狙われない領域を狙って、簡単に狙われない戦い方をしなければいけません」

「まるま×AI のまるま」。

ここでの「まるま」は、特定の業界や分野での **深い専門知識・経験・人脈** のことです。これと AI を掛け合わせれば、汎用 AI には真似できない強みが作れる、という戦略です。

### 中小企業のオーナーには、すでに「まるま」がある

これは、**中小企業のオーナーにとっての朗報** です。

なぜか。中小企業のオーナーは、すでに「まるま」を持っているからです。

たとえば、こういうものです。

税理士・社労士なら、法律と税務の深い専門知識、顧客の財務情報。飲食店オーナーなら、地域の常連客との関係、長年の味の調整。製造業の社長なら、何十年の職人技、業界の人脈。コンサルなら、特定業界の独自ネットワーク、過去案件の知見。

これらに Claude Code を掛け合わせれば、大企業や AI スタートアップが **手が出ない領域** を作れます。

南場さんが「無慈悲」と評する LLM プレイヤーも、神奈川の和食店の常連客の好みは知りません。世田谷の税理士事務所の顧問先の財務状況は知りません。

ここに、中小企業のオーナーの勝ち筋があります。

## 補足：南場さんが感じた「寂しさ」

動画の終盤で、南場さんは個人的な感情を吐露します。

> 「エルデシュ問題、1000 ぐらい問題を残していますけれども、そのうちの 1 つを AI が解いたという話を聞きました」
>
> 「寂しいですね、ちょっと」

エルデシュ問題というのは、20 世紀の数学者エルデシュが残した未解決問題のことです。「人間にしか解けない問題」の象徴と見なされてきました。

その 1 つを AI が解いた。

南場さんが「寂しい」と言ったのは、人間の知的領域に AI が踏み込んできた瞬間に対する、率直な感情です。

ただし、南場さんはこう締めくくります。

> 「この未来は忍び寄るんじゃなくて押し寄せてきます。必ず来ると分かってる未来であれば、私たちもとことん一緒に議論していきたい」

押し寄せる未来から、目を背けない。寂しさを抱きながら、議論から逃げない。

これが、AI 時代の経営者に必要な姿勢だと、私は思います。

## まとめ：明日から始める、4つの行動

ここまでの話を、ひとつにまとめます。

ひとつ。AI による 5〜20 倍の効率化は、現場で起きている実測値です。中小企業の業務でも、同じ比率で起きます。

ふたつ。AI は「サポートツール」から「スタッフ」に進化しました。Claude Code を CLAUDE.md（指示書）で動かせば、自分専用のレモン君が立ち上がります。

みっつ。空いた時間は、空けっぱなしにすると詰まります。社長は、自分自身に対して「乱暴なリーダーシップ」を発揮し、新しい仕事を先にカレンダーに入れます。

よっつ。LLM プレイヤーが無慈悲な時代でも、中小企業のオーナーは「まるま」を持っています。深い業界知識・顧客関係に AI を掛け合わせれば、勝ち筋になります。

南場会長が、ここまで踏み込んで AI 戦略を語った意味は大きい。中小企業のオーナーへの間接的なメッセージとして、私は受け取っています。

## 桜木からのお知らせ：「経営者向けAIの家庭教師」

ここまで読んでいただいて、こう思った方が多いかもしれません。

「DeNA のレモン君と同じことを、自分の会社でやりたい。でも、CLAUDE.md の書き方も、Claude Code のセットアップも、一人でやる自信はない」

これは、ほとんどの経営者の本音です。

私は、それぞれの経営者に伴走する形で、Claude Code の立ち上げから運用までをお手伝いしています。「経営者向けAIの家庭教師」と呼んでいます。

中学生の家庭教師が、わからない問題を一緒に解いてくれるように。社長が「これ、AI にどう頼めばいいのか」と迷った時、いつでも相談できる存在です。

週 1 回のオンライン面談と、Slack でのいつでも質問可能な環境で、3 か月かけて経営者を「自分専用のレモン君を持つ社長」に育てます。プログラミングの知識は不要です。
