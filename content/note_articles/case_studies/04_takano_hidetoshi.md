# Claude Code経営活用事例 #04｜キープレイヤーズ高野秀敏氏の場合

このシリーズでは、有名経営者の公開発言を題材に、**中小企業のオーナーが Claude Code を経営にどう取り入れるべきか** を読み解きます。

第4回は、キープレイヤーズ代表の高野秀敏さんです。

高野さんは、上場10社・EXIT 21社という投資実績を持つ著名な投資家・経営者で、東北大学の特任教授（客員）も務めています。著書『ベンチャーの作法』は5万部超のロングセラーです。

ここまでだと、ほかの著名経営者と変わりません。

ところが高野さんが、このシリーズで特別なのは、**自分自身が経営者として Claude Code を毎日使い、その実体験を note に詳細に記録している** という点です。

南場会長は「DeNA で AI が活躍している」という会社の話。秋好社長は「自分の秋吉システム」を全公開。**ところが高野さんは、「自分はこう使った」「こう挫折しかけた」「こう乗り越えた」という、生々しい実体験** を発信し続けています。さらに、非エンジニア経営者向けセミナーを複数回開催し、参加者の挫折ポイントまで記録しています。

中小企業のオーナーが「自分にもできるかも」と最も思える、貴重な存在です。

本記事では、高野さんが note で公開した4本の記事から、4つの論点を抽出します。最後に、私（桜木）の伴走サービスについてお話しします。

---

## 論点1：月30時間の雑務を、本当に消せるのか

高野さんは、2026年3月の note 記事のタイトルに、こう書きました。

> 「コードを書けない自分が、月30時間の雑務を消した方法」

月30時間。

時間で換算すると、**1日あたり1時間** です。週末2日まるごと使ってもまだ余る、というレベルの時間が浮きます。

具体的にどう消したのか。高野さん自身が公開している、業務別のビフォー／アフターはこうです。

朝の情報整理は、15分から1分。議事録は、10〜15分から「確認のみ」。動画から note や X 用の記事への展開は、1〜2時間から5〜10分。スカウトメールの作成は、5分から30秒。デューデリジェンス（投資先の精査）の情報整理は、半日から30分。

ここで、中小企業のオーナーが感じることは、こうかもしれません。

「投資家だから、こういう業務があるのだろう」

ところが、業務の種類を分解すると、ほとんどが **どの業種の経営者でも発生する雑務** なんです。情報整理、議事録、コンテンツ展開、メール、資料整理。これらは、士業でも、製造業でも、飲食店でも、形を変えて存在します。

つまり、月30時間の雑務削減は、業種を問わず再現可能です。

---

## 論点2：ChatGPT と Claude Code は、何が違うか

高野さんの発言で、いちばん本質的なのが、これです。

> 「ChatGPT は相談相手。Claude Code は右腕」

「相談相手」と「右腕」。

この違いを、中小企業のオーナーに伝わる言葉で説明します。

相談相手は、聞けば答えてくれる存在です。「来週の商談、何を準備すればいい?」と聞けば、ヒントをくれます。ところが、実際の準備（資料作成、相手企業のリサーチ、提案書の下書き）は、自分でやらなければなりません。

右腕は、違います。**自分の代わりに、実務をやってくれる存在** です。「来週の商談、準備お願い」と言えば、相手企業のリサーチをし、提案書の下書きを作り、想定問答を整理して、出してくれます。社長は最終確認だけすればいい。

これが、ChatGPT（相談相手）と Claude Code（右腕）の決定的な違いです。

### なぜ、Claude Code が右腕になれるのか

高野さんは、こう書いています。

> 「『この情報をこう整理して』『このフォーマットで出して』『判断に迷ったら聞いて』
> ……経営者が部下にやっていることと何も変わりません」

ここが核心です。

経営者が、優秀な部下に仕事を任せるとき、どうしているか。

「この案件、こういう形で整理して」「フォーマットはこれで」「判断に迷ったら聞いて」と指示します。Claude Code を使うときも、まったく同じことをします。

つまり、Claude Code の操作で必要なのは、プログラミングの知識ではなく、**人に仕事を任せる能力** です。経営者がいちばん持っているスキルです。

## 論点3：CLAUDE.md は、育てるもの

高野さんが繰り返し強調しているのが、これです。

> 「CLAUDE.md は育てるもの。最初は60点でいい」

CLAUDE.md（クロード・ドット・エムディー）とは、Claude Code に渡す **業務マニュアル** のことです。会社の事情、自分のトーン、好みのフォーマット、判断基準などを書き込んでおきます。

新入社員の研修と、ほぼ同じ発想です。

新入社員に、最初から完璧なマニュアルを渡す会社はありません。最初の数週間で「こういう書き方が好き」「こういう判断はこうしてほしい」と、少しずつ教えていきます。CLAUDE.md も同じです。

最初は60点で十分。使いながら「あ、これ毎回直してる」「ここの判断はこう書いておこう」と、少しずつ追加していく。

### CLAUDE.md に書くべきこと

具体的には、こういう内容を CLAUDE.md に書きます。

会社の事情（業種、規模、主要顧客）。文章のトーン（フォーマル／カジュアル）。よく使うフォーマット（提案書の構成、メールの定型）。よく使う情報源（業界ニュースサイト、過去の議事録の場所）。判断基準（顧客対応で迷ったら、こう対応する）。

これを書いて、Claude Code の動くフォルダに置いておくだけです。

高野さんは、もう一つ重要なことを言っています。

> 「週1回以上やる作業は、全部スキルにしろ」

「スキル」というのは、Claude Code が再利用できる定型作業のことです。週1回でもやる作業は、毎回ゼロから指示するのではなく、「議事録要約スキル」「朝のブリーフィングスキル」のように名前を付けて、何度でも呼び出せるようにします。

これも、新入社員の研修と同じです。同じ作業を毎回ゼロから教える会社はありません。マニュアル化して、再利用します。

## 論点4：「一人だと挫折する」を、高野さんが認めている

高野さんの発言で、私（桜木）がいちばん大事にしているのが、これです。

> 「隣に詳しい人がいれば、壁は一瞬で消える」

これは、高野さんが2026年に開催した非エンジニア経営者向けセミナーのレポートで、参加者の声として記録されています。

つまり、**経営者が Claude Code を一人で立ち上げると、ほぼ確実に挫折する** ということです。

なぜか。

Claude Code は、操作自体は難しくありません。チャット形式で日本語で頼めば動きます。ところが、最初の **環境構築** で躓きます。Mac のターミナルって何? コマンドって何? という段階で、多くの経営者が手を止めます。

そこを越えても、CLAUDE.md の書き方、スキルの作り方、MCP（外部ツールとの連携）の設定など、独学では時間がかかる工程が複数あります。

高野さんがセミナーを開催したのは、まさにこの「一人だと挫折する壁」を越えるためでした。

### セミナーで起きたこと

高野さんのセミナーでは、参加者17人のうち **86% が「スキル作成方法」を最高評価** にしたと記録されています。

セミナーで教えたのは、特別な技術ではありません。CLAUDE.md の書き方、よく使う作業のスキル化、簡単な MCP 設定。これらを、隣で見ながら一緒にやる。それだけで、参加者は半日で「自分のAI秘書を持っている社長」になりました。

ここで、高野さんはセミナー参加者の声をこう紹介しています。

> 「AIが『すごい技術』から『自分の味方』に変わった瞬間」

「すごい技術」のままだと、距離が遠い。「自分の味方」になると、毎日使えるようになる。この変換は、独学では時間がかかりますが、隣に詳しい人がいると、半日で起こります。

## 補足：Claude Pro の月額は、コーヒー代と同じ

高野さんが繰り返し触れている数字が、これです。

> 「Claude Pro 契約料：月額約3,000円」

月額3,000円。

コンビニでコーヒーを1日1杯買うのと、ほぼ同じです。

これで、月30時間の雑務削減が手に入る、と高野さんは主張しています。時給換算で、3,000円÷30時間 ＝ 1時間100円。経営者の時給を考えれば、ほぼタダで秘書を雇うのと変わりません。

ちなみに、Claude を運営する Anthropic 社には、Google が6.4兆円を出資しています。これは、世界中のAI投資の中でも最大級の額です。**それだけのリソースが投入されているAIを、月3,000円で使える** ということです。

時代の話としては、十分に異常な状況だと、私は思います。

## まとめ：明日から始める、4つの行動

ここまでの話を、ひとつにまとめます。

ひとつ。月30時間の雑務削減は、業種を問わず再現可能です。情報整理、議事録、メール、資料整理、コンテンツ展開、いずれも5〜20倍の効率化が起こります。

ふたつ。Claude Code は「相談相手」ではなく「右腕」です。経営者が部下に出している指示と同じ要領で、実務を任せられます。

みっつ。CLAUDE.md（取扱説明書）は、最初60点でOK。新入社員の育成と同じで、使いながら育てます。週1回以上やる作業は、すべてスキル化します。

よっつ。一人で立ち上げると、ほぼ挫折します。隣に詳しい人がいれば、壁は一瞬で消える、というのは高野さん自身の主張です。

高野さんが note で繰り返し書いていることは、私が現場で経営者に伝えていることと、ほとんど一致します。Claude Code は、経営者にとって最強の道具になり得る。ただし、最初の壁を越えるには、伴走者が必要だ、ということです。

## 実装の手引き：自分の会社の「Claude Code 右腕」を立ち上げる具体手順

ここからは、高野さんが推奨している Claude Code の使い方を、**社員5〜30人規模の中小企業オーナーが、自分の手で再現するための具体手順** を示します。

### 用意するもの（合計：月額3,000円＋無料）

- Claude Pro 契約（月額3,000円）
- パソコン（Mac か Windows、メモリ8GB 以上）
- Claude Code（無料、Anthropic 公式サイトからインストール）
- 任意の作業フォルダ（例：デスクトップに `claude-management` フォルダを作る）

### Step 1：CLAUDE.md（取扱説明書）を書く（所要60分）

作業フォルダに `CLAUDE.md` という名前のテキストファイルを作り、以下の質問に答える形で書き出します。

```markdown
# 私の会社についての取扱説明書（CLAUDE.md）

## 会社の基本情報
- 業種：（例：神奈川県横浜市の和食店）
- 規模：社員 5 名（パート含めて 12 名）
- 主要顧客：地元の常連客 7 割、観光客 3 割
- 売上規模：年商 8,000 万円
- 創業：2018 年

## 今期の3つの目標
1. 売上：年商 1 億円達成
2. 常連リピート率：60% → 70%
3. 新メニュー開発：四半期に1つ

## 私（社長）の判断の癖
- 値段交渉は基本しない（価値で売る方針）
- 採用は人柄重視、スキルは後から教える
- 数字より顧客の声を優先する場面が多い
- 直感的に「合わない」と感じる案件は、たいてい後でトラブルになる

## 文章のトーン
- お客様向け：丁寧、温かみのある言葉、絵文字なし
- 取引先向け：簡潔、結論ファースト
- 社内向け：率直、ねぎらいの一言を必ず添える

## 私が AI に絶対やってほしくないこと
- 顧客に直接 DM を送る（必ず私が承認してから送信）
- 値段の設定（私の判断でしか変えない）
- 退職判断・採用最終判断
```

ここまで書ければ60点。高野さんが言う「最初60点でOK、使いながら育てる」の出発点です。

### Step 2：朝のブリーフィング・スキルを作る（所要45分）

作業フォルダの中に `.claude/skills/morning-briefing/` というフォルダを作り、`SKILL.md` を以下の内容で作成します。

```markdown
---
name: morning-briefing
description: 朝起きた時に確認したい今日のスケジュール・重要メール・業界ニュースを整理する
---

# 朝のブリーフィング・スキル

## やること
1. Google カレンダーから今日の予定を取得
2. メールから昨日 18:00 以降の未読を確認
3. 業界ニュースサイトから直近24時間の記事を5件取得
4. 上記から「今日、社長が知っておくべき重要事項」を10行以内で要約

## 注意事項
- 経営コンテキスト（CLAUDE.md）の判断癖を必ず参照する
- 朝6:00 に自動実行する（cron か Slack Bot 経由）
- 出力は Slack に投稿、長文にしない
```

Claude Code を立ち上げて「morning-briefing スキルを実行して」と日本語で頼めば、手順に従って動いてくれます。

### Step 3：会議トラッカーを作る（所要30分）

会議が終わるたびに、Claude Code に以下の質問をするだけです。

```
今日の◯◯会議の議事録は ./meetings/2026-05-10_◯◯.md にある。
この会議を100点満点で評価して、点数と理由を ./meetings/tracker.md に追記して。
評価基準：
- 議題が明確だったか（30点）
- 結論が出たか（30点）
- 次のアクションが決まったか（20点）
- 時間内に終わったか（20点）
```

これを2週間続けると、`tracker.md` には自分の会議の傾向が記録されます。

### Step 4：フィードバックループを回す（毎週金曜15分）

毎週金曜日の終業前に、Claude Code にこう頼みます。

```
今週の議事録（./meetings/2026-05-10〜2026-05-14）と
朝のブリーフィング履歴（./briefings/）を読んで、以下を教えて：
1. ブリーフィングで提示した「私からの一言提案」は、実際の意思決定に役立ったか
2. 今週の会議で、CLAUDE.md に追記すべき新しい判断パターンはあったか
3. 来週、改善すべきブリーフィングのフォーマットはあるか
```

ここで提案された改善点を、CLAUDE.md と SKILL.md に追記する。これがフィードバックループです。Claude Code が「便利ツール」から「右腕」に変わるのは、ここから先です。

### よくあるつまずきポイント

中小企業のオーナーが Step 1〜4 を進める時、典型的につまずくのは次の3点です。

**つまずき1：そもそもターミナルや Claude Code のインストールができない**
独学では1〜2週間かかります。誰かに横で教えてもらえれば30分で終わります。

**つまずき2：CLAUDE.md が育たない**
最初の60点を書いた後、追記する習慣が続きません。週1回の振り返り時間を、自分のスケジュールに「予約」しておくのが対策です。

**つまずき3：スキルの設計がうまくできない**
「何を入力に、何を出力させるか」の設計が、独学では難しい。ここは、誰かと一緒に考えるのが圧倒的に早いです。

高野さん本人が「隣に詳しい人がいれば、壁は一瞬で消える」と書いている通りです。

## 桜木からのお知らせ：「経営者向けAIの家庭教師」

ここまで読んでいただいて、こう思った方が多いかもしれません。

「Claude Code を使えるようになりたい。でも、高野さんのセミナーは、すぐに次の開催があるとは限らないし、自分一人で立ち上げる自信はない」

これは、ほとんどの経営者の本音です。

私は、それぞれの経営者に **完全1対1で伴走** する形で、Claude Code の立ち上げから運用までをお手伝いしています。「経営者向けAIの家庭教師」と呼んでいます。

中学生の家庭教師が、わからない問題を一緒に解いてくれるように。社長が「これ、AIにどう頼めばいいのか」と迷った時、いつでも相談できる存在です。

週1回のオンライン面談と、Slack でのいつでも質問可能な環境で、3か月かけて経営者を「自分専用の右腕を持つ社長」に育てます。プログラミングの知識は不要です。

高野さんが言う「隣に詳しい人がいれば、壁は一瞬で消える」を、私は1対1で実装しています。
