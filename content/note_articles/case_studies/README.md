# 経営者AI活用事例｜記事シリーズ運営マニュアル

> 著名経営者・スモールビジネスオーナーのClaude Code・AI活用事例を継続的にnote発信するための運営方針です。
> **法的・倫理的に安全な記事制作** を最優先します。

---

## ⚠️ 絶対に守るべきルール

### ❌ やってはいけないこと

1. **公開されていない情報を記事化しない**
   - 直接インタビューしていない発言を引用しない
   - SNSで言っていないことを "言ったこと" にしない
   - 未確認情報を断定的に書かない

2. **引用元を明示せずに発言を載せない**
   - 必ず出典URL or 媒体名を明記
   - 動画なら「YouTube：[番組名] 第〇回（YYYY年MM月公開）」

3. **具体的な数字を捏造しない**
   - "DeNAは月100時間取り戻した" ←公開発表がなければNG
   - 一般論として書く or 推測として明示する

4. **本人に許諾なく "AI事例本" として深く語らない**
   - 公開されている範囲のみ
   - 解釈・推測は明確に "推測" と明示

### ✅ やるべきこと

1. **公開発言の正確な引用**：出典付き
2. **公開記事・動画の "要約 + 解釈"**：「〇〇氏は△△と語っています（出典：XXX）」
3. **業界一般論との接続**：「これは経営者一般に言える傾向です」
4. **明確な仮説・推測の表示**：「もし〇〇氏がClaude Codeを使ったら、こう活用するでしょう（推測）」

## 記事の3つの型（安全な書き方）

### 型A｜公開発言ベースの考察記事
**「DeNA南場会長のAI観から読み解く、経営者がClaude Codeを使うべき3つの理由」**

- 公開されているインタビュー・講演から引用
- それを踏まえて "こんな活用が想定される" を提示
- 必ず出典明示

### 型B｜業界トレンド記事（個人を直接題材にしない）
**「日本の経営者がAI活用で進めている3つの方向性｜代表的な事例から考察」**

- 複数の経営者の公開情報を横断的に分析
- 一般論として書く
- 個別事例は "公開されている範囲" のみ言及

### 型C｜架空・仮名ペルソナ記事
**「ある SaaS創業者の Claude Code活用日記｜社員5名のCEO、Aさんの場合」**

- 完全に架空 or 自分のクライアント（仮名）
- 著名人を直接題材にしない
- "リアリティのある仮想シナリオ" として明示

---

## 推奨：型A＋型C のハイブリッド戦略

### 戦略
- **型A** で著名経営者の公開発言を「考察素材」として使う（集客）
- **型C** で具体的なシナリオを描く（読者の "自分ごと化"）
- これにより **法的に安全** かつ **集客力のある** 記事ができる

### 例
```
タイトル：「DeNA南場会長が語った "経営者のAI活用" を、
スモールビジネスに翻訳すると｜Claude Code 実践活用法」

構成：
1. 南場会長の公開発言を引用（型A）
2. その思想を一般経営者に翻訳
3. スモールビジネス経営者の仮想ストーリー（型C）
4. Claude Code での具体実装方法
5. CTA（無料相談・パッケージ）
```

→ 著名経営者の思想を借りて、スモールビジネス向けに展開する。
→ 直接の引用は公開発言のみ、創作部分は "仮想シナリオ" と明示。

## 安全な記事制作フロー（5ステップ）

### Step 1｜情報収集
- 上記キーワードで検索
- ヒットした記事・動画のURLをリスト化
- 引用したい部分をクリップ（出典付き）

### Step 2｜引用可能性の判断
- 以下のいずれかに該当 → 引用OK
  - 公式メディア掲載のインタビュー
  - 本人運営のSNS・note・ブログ
  - 公開講演（YouTubeアーカイブ等）
- これらに該当しない → 引用NG（記事化しない）

### Step 3｜骨組み作成
- 著名人の発言は **直接引用** の形で（30字以下推奨）
- 解釈・展開は自分の言葉で
- 仮想シナリオは "仮名・仮想" と明示

### Step 4｜記事執筆
- 出典を必ず明記
- 引用元のリンクも貼る（公開記事の場合）
- 推測・解釈は "私はこう考える" のスタンスで

### Step 5｜ファクトチェック
- 公開前に、引用部分を再度元ソースで確認
- 数字・固有名詞・日付を確認
- 誤った情報がないか最終確認

## 法的リスクへの対処

### 万が一のための備え

1. **記事URL を本人に DM/メールで送る**（事前 or 事後）
   - "こういう記事を書きました。修正要望があればお知らせください" の文面
   - 関係性が築ければ、むしろ歓迎されることも

2. **修正・削除依頼への即対応**
   - 修正：3営業日以内
   - 削除：48時間以内

3. **収益化との関係**
   - 著名人の名前を使った記事で広告収益を得る場合は、より慎重に
   - 紹介手数料・パッケージ販売への誘導は、本人の言及と紐付けない

4. **顧問弁護士への相談**
   - 月1万円程度のスポット契約も検討
   - 著名人言及記事は事前にチェック依頼
