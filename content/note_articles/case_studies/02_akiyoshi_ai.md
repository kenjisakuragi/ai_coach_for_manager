# Claude Code経営活用事例｜ランサーズ秋好社長の場合

このシリーズでは、有名経営者の公開発言を題材に、**中小企業のオーナーが Claude Code を経営にどう取り入れるべきか** を読み解きます。

第2回は、ランサーズ株式会社の社長、秋好陽介さんです。

ランサーズと言えば、フリーランスや個人事業主の働き方を支える上場企業です。この会社の社長が、2025年5月の通期決算説明会で、AI に対する考え方を、踏み込んだ形で述べました。

決算説明会というのは、本来、業績の数字を読み上げる場です。ところが秋好さんは、「自分自身が AI を使う」という社長個人の宣言と、「人材は5倍、10倍働ける」という生産性の数字を、株主の前で語りました。

これは、なかなか珍しいことです。

なぜ社長が、ここまで踏み込んだのか。そして、ここから中小企業のオーナーは、何を持ち帰るべきなのか。

本記事では、秋好さんの発言を4つの論点に整理します。最後に、私（桜木）が経営者の方に伝えていることを、お話しします。

---

## 論点1：「AX」とは何か。なぜ今これが重要なのか

秋好さんは、ランサーズの方針をこう述べています。

> 「日本の産業をまさに AX、AI で AI トランスフォーメーションしていく」
>
> 「AX で日本産業をアップデートすることにフルコミットしていきたい」

ここで「AX」という言葉が出てきます。

これは「AI トランスフォーメーション」の略で、簡単に言えば、**AI を前提に、仕事のやり方そのものを組み直す** という意味です。

少し前まで、世の中は「DX（デジタル化）」と言っていました。紙の書類を電子化する、対面の会議をオンラインにする、こういった変化です。

ところが、DX と AX は、根本から別物です。

DX は、人間がやっていた仕事を、デジタル道具で速くする話でした。打つのは人間です。

AX は、人間がやっていた仕事の一部を、AI が代わりにやる話なんです。

たとえば、議事録の作成を考えてみてください。DX 時代までは、ノートではなくパソコンで打つ、という変化でした。AX 時代では、議事録は、もう人間が打ちません。AI が録音から自動で書き起こし、要点をまとめます。人間がやるのは、最後のチェックだけ。

仕事の主役が、人間から AI に移っているわけです。

### 「フルコミット」と言わせた、業界の危機感

秋好さんが「フルコミット」、つまり「全力で取り組む」という強い言葉を使ったのには、理由があります。

技術の波に乗り遅れた会社は、長く生き残れません。

ただし、過去の波と AI の波には、決定的な違いがあります。**普及までの時間が、極端に短い** のです。

ChatGPT が世に出たのが 2022 年 11 月。それから 3 年で、すでに個人事業主の小さな仕事にまで降りてきています。これは、過去の技術革新と比べて、桁違いの速さです。

つまり、こういうことです。

3 年遅れで動き出すと、その時には業界の風景が変わってしまっている。秋好さんの「フルコミット」は、その危機感の表れだと、私は読みます。

中小企業のオーナーにとっては、こういう質問になります。

**「あなたの業界で、競合が AI で動き始めるまでに、あと何年ありますか」**

業界によって違いますが、士業・コンサル・小売・飲食、いずれも 1〜2 年です。

## 論点2：AI に任せる仕事と、社長が向き合う仕事を、どう分けるか

秋好さんの発言の中で、いちばん実務に効くのが、これです。

> 「AI でできるところは AI でいいよ、もしくは AI でできない人間しかできないところのラストワンマイルを人間でやってほしい」

「ラストワンマイル」という言葉、聞いたことがあるでしょうか。

もともと物流の業界用語です。商品を運ぶ時、東京から大阪までトラックで運ぶ部分は機械的にできます。ところが、最後にお客さんの玄関先まで届ける、その「最後の 1 区間」だけは、どうしても人の手が必要になる。これを「ラストワンマイル」と言います。

秋好さんは、この言葉を AI の議論に持ち込みました。

仕事の大部分は AI に任せていい。ただし **「最後の出口」だけは人間が担う**。これが、AI 時代の業務設計の中核です。

### 自社の業務を、紙の上で2列に分ける

ここで、自分の仕事を頭の中に並べてみてください。

メールの返事。請求書の作成。提案書の下書き。リサーチ。SNS への投稿。経理の仕分け。スケジュール調整。常連客への対応。社員の評価面談。新規事業の意思決定。価格交渉。

このうち、AI に任せられるのは、おおむね前半です。後半、つまりお客さんとの関係や、責任を伴う判断は、社長が向き合うべき領域です。

私のクライアントで、神奈川で和食店を営む S さんという方がいます。先日、この話をしました。S さんはしばらく考えて、こう答えました。

「議事録もメールも AI に任せていい。でも、常連さんの誕生日に出すお品書きは、絶対に自分で考えたい」

これが、まさに秋好さんの言うラストワンマイルです。

仕事には、機械的に処理できるものと、その人にしかできないものがあります。後者は、お客さんとの関係や、最終的な責任を取ることに関わります。

ここを言葉にして、紙に書き出す。それだけで、AI 導入が驚くほど進みます。書き出さないと、いつまでも「全部自分でやらなきゃ」という思考から抜けられません。

これは私の経験ですが、書き出すのに 30 分。それで月 30 時間が浮く道筋が見える経営者が、ほとんどです。投資対効果としては、悪くない 30 分だと思います。

## 論点3：社長が、誰よりも先に AI に触る

秋好さんの発言で、いちばん覚悟が出ているのは、ここです。

> 「私含めた社員 1 人 1 人が AI ネイティブになることによって、よりこのプロダクトを作る模範となるような会社にしていきたい」

「私含めた」。

この三文字に、上場企業の社長としての覚悟が出ています。

社員に「AI を使え」と号令だけかけて、自分は触らない社長。多くの会社で、これが現実です。誰かが整理してくれた要約を見て、わかったつもりになる。これでは、社員は動きません。

### なぜ、社長が選ぶべき AI が Claude Code なのか

ここで、中小企業のオーナーが選ぶべき AI は何か、という話になります。

ChatGPT や Gemini は、相談相手としては優秀です。ところが、経営者が本当に必要なのは「相談」ではなく「実務」です。議事録を書く。メールを下書きする。資料をまとめる。リサーチする。

ここで力を発揮するのが、Claude Code です。

Claude Code は、もともとプログラマー向けの AI として開発されました。ところが実際には、経営者の業務にも極めて相性がいい。理由は3つあります。

第 1 に、**1 度指示したことを覚えてくれます**。「うちの会社の事情はこうだ」「この顧客の好みはこうだ」と教え込んでおくと、次回から自動的に考慮してくれます。

第 2 に、**自律的に動きます**。「今週の業界ニュースをまとめて」と指示すれば、自分でニュースサイトを巡回し、要点を整理し、レポートを返してきます。社長が指示を細かく出さなくても、勝手に進めてくれるわけです。

第 3 に、**ファイルや資料を直接扱います**。PDF、Excel、Word など、経営者が普段から使っているファイル形式を、ほぼそのまま処理できます。

つまり Claude Code は、相談相手ではなく **実務をする秘書** として機能します。

ただし、ここに落とし穴があります。Claude Code は、適切に指示を出さないと、本来の力を出しません。プログラマーではない経営者が独学で始めると、3 週間で挫折するケースが多いんです。

### 4つの段階で、社長が AI ネイティブになる

中小企業のオーナーが Claude Code を使えるようになるには、段階を踏む必要があります。

第 1 段階。朝のニュース整理を、Claude Code に任せます。毎朝 15 分かけていた作業が、1 分で終わるようになる。「あ、本当に楽になる」という体感を、まず得ます。

第 2 段階。いつもやっている定型業務、議事録や提案書の下書き、SNS の投稿などを任せます。1 か月続けると、月 30 時間ほど時間が浮きます。これで初めて「AI が仕事の景色を変える」と実感します。

第 3 段階。判断に迷う時、Claude Code を「壁打ち相手」として使います。「この案件、進めるべきか迷っている。賛成意見と反対意見をそれぞれ整理して」と頼めば、論点が一気に整理されます。経営者の意思決定の孤独が、軽くなります。

第 4 段階。自分の業界知識や顧客情報を、Claude Code に教え込みます。これを「CLAUDE.md（クロードに教える取扱説明書）を育てる」と呼びます。ここまで来ると、Claude Code が「自分専用の参謀」として動きます。

この 4 段階を 3 か月で進めれば、号令ではなく、実装で「私含めた」を体現できます。

## 論点4：「5倍、10倍」の生産性。本当のところ、どこまで行けるか

秋好さんは、こんな数字も出しています。

> 「1 人で今までできていたことを 1 とすると、場合によっては 5 とか 10 倍のアウトプットを……出せる」

5 倍、10 倍。

正直に言います。私は、この数字をお客さんにそのまま伝えません。

なぜか。最初の 3 か月で 5 倍は、まず出ないからです。

5 倍とか 10 倍という数字は、いくつかの効率化が掛け算で重なって、初めて成立します。

たとえば、議事録の作成時間が 30 分から 90 秒になる。これだけで 20 倍です。リサーチが 2 時間から 10 分になる。これは 12 倍です。こういった個別の効率化が積み上がり、判断の質が上がり、社員にも展開されて、ようやく全体で 5 倍、10 倍に届きます。

### 3 か月で目指せる、現実的な数字

何人もの経営者と一緒に AI 導入を進めてきた経験から言うと、3 か月で目指せるのは **2 倍** です。

具体的には、月 40 時間あった雑務が、16 時間に減ります。浮いた 24 時間を、新規開拓や戦略を考える時間に使う。これだけで、社長の景色は完全に変わります。

5 倍、10 倍は、半年から 1 年かけて、段階的に積み上げる数字です。

ここを焦ると、3 か月目で挫折します。「思ったほど効果が出ない」と、やめてしまうわけです。

順番が逆なんです。

最初は 2 倍を確実に取りに行く。次に 3 倍、4 倍と積み上げる。半年後にふと振り返ると、5 倍に届いている。これが、無理なく続く道のりです。

## 補足：仕事だけでなく、生活でも AI を使う

秋好さんの発言で、もうひとつ注目したいものがあります。これは決算ではなく、釣りの専門誌のインタビューです。

> 「いまなら AI エージェントがあるので、相模湾で何が釣れているか、といった情報を自動収集できます」

社長が、趣味の釣りで AI を使っている。

ここに、AI に慣れる近道があります。

仕事道具としてだけ使う人は、なかなか上達しません。「使え」と言われたから使う、になるからです。

ところが、献立の提案、旅行先のリサーチ、子どもの宿題のサポートなど、生活の中で使い始めると、驚くほど早く慣れます。生活で使い慣れた経営者は、仕事でも自然に使えるようになる。

AI ネイティブになる近道は、実は仕事ではなく、日常生活なんです。

## まとめ：明日から始める、4つの行動

ここまでの話を、ひとつにまとめます。

ひとつ。AI による仕事の作り直しは、もう始まっています。3 年遅れると、業界の風景が変わってしまっている。今、動き始める価値があります。

ふたつ。仕事を「AI に任せるもの」と「自分にしかできないもの」に分けて、紙に書き出します。書き出しに 30 分。そこから月 30 時間が浮きます。

みっつ。社長が、誰よりも先に Claude Code に触ります。号令ではなく、自分の手で触ることから始めます。

よっつ。3 か月で 2 倍を取りに行き、半年で 3〜5 倍、1 年で 5〜10 倍を目指します。最初から大きな数字を狙うと、ほぼ折れます。

ランサーズの秋好社長が、ここまで明確に「経営者を含めて、みんなが AI を使うべきだ」と言いました。これは、上場企業の話ではありません。中小企業のオーナー一人ひとりへのメッセージだと、私は受け取っています。

## 桜木からのお知らせ：「経営者向け AI の家庭教師」

ここまで読んでいただいて、こう思った方が多いかもしれません。

「Claude Code を使うべきなのは、わかった。でも、自分一人で立ち上げて、4 段階を 3 か月で進める自信はない」

これは、ほとんどの経営者の本音です。

私は、それぞれの経営者に伴走する形で、Claude Code の立ち上げから運用までをお手伝いしています。「経営者向け AI の家庭教師」と呼んでいます。

中学生の家庭教師が、わからない問題を一緒に解いてくれるように。社長が「これ、AI にどう頼めばいいのか」と迷った時、いつでも相談できる存在です。

週 1 回のオンライン面談と、Slack でのいつでも質問可能な環境で、3 か月かけて経営者を AI ネイティブに育てます。プログラミングの知識は不要です。
