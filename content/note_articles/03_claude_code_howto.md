## ステップ② Claude Code をインストール｜10分

### Mac の場合

ターミナル（"Terminal.app"）を開いて、以下を貼り付け：

```bash
brew install anthropic/cli/claude
```

> ⚠️ Homebrew が入っていない方は、まず以下：

> /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
> ```

PowerShell を **管理者として実行** で開いて：

```powershell
# Node.js をまずインストール（公式インストーラー）
# https://nodejs.org/ja からダウンロード

# その後
npm install -g @anthropic-ai/claude-code
```

→ バージョン番号が表示されたらOK。

## ステップ④ あなた専属の "取扱説明書"（CLAUDE.md）を作る｜10分

### 作業ディレクトリの準備

```bash
cd ~
mkdir AI_Chief_of_Staff
cd AI_Chief_of_Staff
```

→ ホームディレクトリに `AI_Chief_of_Staff` というフォルダができます。

### CLAUDE.md を作成

同じターミナルで：

```bash
touch CLAUDE.md
open CLAUDE.md     # Mac
notepad CLAUDE.md  # Windows
```

エディタが開きます。以下のテンプレを貼り付けて、自分用に書き換えてください：

```markdown
# 〇〇さんのClaude取扱説明書

## 私について
- 名前：〇〇 〇〇
- 会社名：〇〇株式会社
- 役職：代表取締役
- 事業：（一行で）

## 私の好み
- 文章のトーン：です・ます調
- 長さ：簡潔（A4半分以内）
- 絵文字：使わない

## 私が大事にしていること
- 意思決定はスピード重視
- 顧客視点を忘れない
- 数字で判断する

## 触れない話題
- 機密情報は仮名化（X-社、Y-社）
- 触れない話題：〇〇関連は私の判断を待つ

## アウトプットのデフォルト
- 議事録要約は最後に "私が次に判断すべきこと" を必ず追加
- メールは初稿後に "別案も提示してください"
```

→ 自分の情報を埋めて保存。

## ステップ⑤ 議事録要約スキルを作る｜10分

最も即効性があり、月10時間の取り戻しに直結するスキルです。

### スキルファイルの作成

```bash
mkdir skills
touch skills/meeting_summary.md
open skills/meeting_summary.md
```

以下を貼り付け：

```markdown
# 議事録要約スキル

## 目的
会議の文字起こしから、決定事項・宿題・私の判断ポイントを90秒で抽出する。

## 入力
- 会議の文字起こしテキスト（.txt）
- または録画ファイル

## 出力フォーマット

### 📋 会議の概要
（30字以内で：いつ・誰と・何の会議だったか）

### ✅ 決定事項（経営判断のみ）
- 1
- 2

### 📝 次のアクション
| 担当 | アクション | 期限 |
|---|---|---|
|  |  |  |

### 💭 論点として残っているもの
- 1
- 2

### ⚡ 〇〇さん（私）が次に判断すべきこと
- 1
- 2

## トーン
- 簡潔。です・ます調。
- 全体でA4半分以内。
- 推測には [推測] タグを付ける。
- 数字や日付は必ず原文ママ。
```

→ 保存。

### 実際に使ってみる

会議の文字起こしファイル（仮に `meeting.txt`）を `inputs/` ディレクトリに置きます：

```bash
mkdir inputs
# meeting.txt を inputs/ に置く
```

ターミナルで：

```bash
claude
> skills/meeting_summary.md を使って、 inputs/meeting.txt を要約して
```

→ **90秒以内に要約が出力されます**。

## よくある質問（先回り回答）

### Q1. 機密情報をAIに渡しても大丈夫？
**A.** Anthropic社（Claudeの提供元）はAPI送信データを学習に使わないと契約で明示しています。
さらに念のため、CLAUDE.md に「顧客名は X-社、Y-社 と仮名化する」と書いておけば、運用上は安全です。

### Q2. インストールでつまずいたら？
**A.** Mac の brew が入っていないケースが最多です。
公式（https://brew.sh/index_ja）から手順通りインストールすれば解決します。

### Q3. 文字起こしは何を使う？
**A.** Zoom Pro の自動文字起こし、または tldv（無料プランあり）が便利です。

### Q4. これを覚える時間がない
**A.** 30分で動かせる設計です。
ただし、本格運用には3か月の慣れが必要。私のような伴走サービスを使うのも手です。

### Q5. 結果が思ったように出ない
**A.** CLAUDE.md とスキルファイルの "書き方" で大きく変わります。
3-5回の試行錯誤で、自分仕様に育っていきます。
