# JVキックオフMTG資料｜30分の合意形成

> 30分のオンラインMTGで使う、画面共有用のスライド原稿（または口頭プレゼン資料）です。
> Marp / Google Slides / Keynote のいずれにも変換可能な構成にしています。
> 各セクションを1スライドとして扱ってください。

---

## MTGのゴール（自分用メモ）

- 共催の合意を取る
- 報酬条件を握る
- 配信タイミングを決める
- 次のアクションを確定する

## 30分のタイムテーブル

| 時間 | 内容 | スライド番号 |
|---|---|---|
| 0〜3分 | アイスブレイク・趣旨説明 | 1 |
| 3〜10分 | このライブの内容と狙い | 2-4 |
| 10〜20分 | パートナーシップの設計 | 5-8 |
| 20〜25分 | 想定される疑問への回答 | 9-10 |
| 25〜30分 | 次のアクション確定 | 11-12 |

## スライド 2｜なぜこのライブを始めるのか（1分）

```
背景

経営者の方とAI活用の話をしていて、いつも同じ壁にぶつかります。

  「ChatGPTは触ったけど、自分の業務でどう使うかが見えない」
  「プログラミングが必要なら無理」
  「業務は変わらないまま、契約だけ続いている」

この壁を、120分のライブ実演で壊しに行きます。
```

**話すポイント**：
- 自分自身が経営者として直面した実体験を一言入れる
- 抽象論ではなく実演重視の構成であることを強調

## スライド 4｜ターゲット（〇〇さんのリストと合うか）

```
このライブが向いている方

  ✓ AIに興味あるけど、何から始めればいいか悩んでいる経営者
  ✓ ChatGPTは試したけど続かなかった人
  ✓ 「プログラミングは無理」と諦めている社長
  ✓ 秘書を雇うほどではないけど雑用に追われている経営者

向いていない方（リスト全体に投げる必要はない）

  ✕ すでにAIをガンガン使い倒している人
  ✕ プログラミングの技術論を聞きたい人
```

**話すポイント**：
- 「〇〇さんのリストの中で、こういう方は何割くらいいると感じますか？」と質問を投げる
- 配信時に件名でフィルタリングするので、リスト全体に響かなくてOK

## スライド 6｜報酬設計（核心）

```
報酬

  β価格期（¥10,000）：1名成約あたり ¥4,000（40%）
  正規価格期（¥29,800）：1名成約あたり ¥11,920（40%）

例：1配信で20名成約した場合
  β期：¥80,000
  正規期：¥238,400

  ※ 業界標準は20〜30%が多い中で、40%設定
  ※ 〇〇さんへの即時リターンを最大化する設計です
```

**話すポイント**：
- 業界標準より高めだという事実を伝える
- 月単位ではなく「配信ごと」に確定する仕組みを強調

```
  振込手数料は弊社負担
  振込前に成約数の確認をご依頼します
```

## スライド 9｜よくある質問（先回り）

```
Q. 〇〇のリストには合わない方も多いのでは？
   → 配信文面の件名で「経営者」「AI活用」とフィルタリング。
     合わない方はそもそも開かない／申込まないので、
     配信時の絞り込みで調整可能です。

Q. β価格期間はいつまで？
   → 検証KPIを見ながら最初の3回程度。
     CVRが安定したら正規価格 ¥29,800 へ移行（その時点で報酬は¥11,920に増額）。

Q. もし合わなかったら？
   → 1回の配信ごとに判断OKです。
     最低継続義務はありません。
```
