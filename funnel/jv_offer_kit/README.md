# JVオファーキット｜目次

JVパートナー2名（既存）に共催を提案し、実行に移すための一式資料です。
順番にこれらを使えば、合意形成から実行までスムーズに進められます。

## ダウンロード方法

### 方法A｜単一ファイル（推奨・印刷／PDF化向け）
👉 [`JV_Kit_Complete.md`](./JV_Kit_Complete.md) （全資料を1ファイルに統合）

### 方法B｜ZIPで一括ダウンロード（個別編集向け）
👉 [`../jv_offer_kit.zip`](../jv_offer_kit.zip) （個別ファイル一式）

### 方法C｜個別ファイルを参照
下記の一覧から必要なものだけ参照

## 想定フロー

```
[Day 0]   提案書（01）をメールで送付
          ↓
[Day 3-5] キックオフMTG設定（30分）
          ↓
[Day 7]   キックオフMTGで合意形成（02を使用）
          ↓
[Day 8]   契約書（03）を締結（電子署名でOK）
          ↓
[Day 14]  配信日確定、配信文面（jv_email.md）を共有
          ↓
[Day 21]  パートナーが配信1回目（開催14日前）
          ↓
[Day 32]  パートナーが配信2回目（開催3日前）
          ↓
[Day 35]  ウェビナー開催
          ↓
[Day 38]  成果速報レポート（05）を送付
          ↓
[Day +30] 月次レポート＋報酬支払い
```

## 重要なスタンス

- **対等なパートナー**として接する（依頼者ではない）
- **数字で語る**（「読者にとってこういう価値がある」を明示）
- **長期目線**を伝える（一発で終わるのではなく継続関係を作りたい）
- **無理強いしない**（β価格期は条件が厳しいので、合わなければ素直に引く）
