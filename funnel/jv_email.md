# JVパートナー向け｜メルマガ配信文面テンプレ集

## 設計の前提

### この文面の使い方
- JVパートナー2名がそれぞれ自分のメルマガリストに配信する
- 件名・本文ともに **パートナーの普段のトーンに合わせて軽く編集してもらう前提**
- **2回配信** が基本（初回告知・締切前リマインド）
- 配信タイミング：ウェビナー開催の14日前と3日前

### JVパートナーへの伝達事項（同梱）
- 報酬：成約1名あたり **¥4,000（β価格¥10,000の40%）**、確立後は ¥11,920（¥29,800の40%）
- 計測方法：申込フォームに紹介元コード（パートナー固有のUTMパラメータ）を埋め込む
- 報酬支払い：ウェビナー開催から3営業日以内に確定額を共有、月末締め翌月15日払い

## β価格（¥10,000）期から正規価格（¥29,800）期への移行時の文面変更

### 件名・本文の差分

#### β期の言い回し
> 「今回はβ価格 ¥10,000 で、次回以降は ¥29,800 に上がる予定です」

#### 正規価格期の言い回し
> 「参加費は ¥29,800（税込）。経営者の方の月30時間を取り戻す120分の投資としてご検討ください」
> （価格訴求の補強として、"取り戻す時間の時間単価" を入れる）

### 価格上昇のお知らせ（最終β価格回の前）
β期最終回前のメルマガに以下を追加：

```
【お知らせ】
このウェビナーは、〇月開催分まではβ価格 ¥10,000 です。
〇月以降は通常価格 ¥29,800 になります。

「とりあえず一度見てみたい」という方は、
β価格期にご参加いただくのをお勧めします。
```

→ 心理的に "今のうちに" を意図的に演出。希少性は事実ベースで。

## JVパートナーとの運用フロー

### 各回のスケジュール（開催日を D0 とする）

|---|---|

| D-21 | 配信文面のドラフトをパートナーに共有（カスタマイズしてOK） |

## 紹介元計測の技術的設計

### URL構造
```
https://[ドメイン]/webinar?utm_source=[partner_id]&utm_medium=email&utm_campaign=[campaign_name]
```

例：パートナーAの場合
```
https://example.com/webinar?utm_source=partner_a&utm_medium=email&utm_campaign=2025_05_webinar
```

### 計測実装
- LP側でutm_sourceをCookieに保存（30日有効）
- Stripeの決済時、`utm_source` をmetadataに記録
- Notion/Google Sheetsへの自動転記スクリプト（次のタスク #4 で構築）

### パートナー間で重複した場合のクレジット
- **First-touch優先**（最初にCookieが入ったパートナーに報酬）
- LPに到達してから決済までの期間が30日を超えた場合はオーガニック扱い
