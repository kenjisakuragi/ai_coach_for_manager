# AIオペレーションスタック構築仕様

## 設計思想

### 根本方針
**「人間が必ず握る領域」と「AI＋自動化に委ねる領域」を最初から線引きする。**
副業（週20時間）で月利100万円以上を維持するには、後付けの自動化では間に合わない。事業立ち上げ初月から組み込む。

### 人間が必ず握る領域
- ウェビナー本番のライブデモ
- 個別診断の15分ZoomMTG
- 法人提案の最終MTG
- ブランドメッセージとコンテンツの最終承認
- 月1グループ会のファシリテーション

### AI＋自動化に委ねる領域
- 申込→決済→Slack招待→ウェルカムメール一気通貫
- ウェビナー録画→note/X記事の自動生成
- 問い合わせ・FAQ一次回答
- Slack質問のAIドラフト→人間承認
- 月次JV報酬レポート
- CRM／LTV分析

## 自動化フロー詳細

### フロー1｜ウェビナー申込→決済→Slack招待

#### トリガー
LP上のフォーム送信

#### 処理ステップ
1. **Stripe Checkout** で ¥10,000 決済
2. **Make** が Stripe Webhook を受信
3. Notionの「ウェビナー申込」DBに新規レコード作成（氏名／会社／メール／業務悩みTOP3／utm_source）
4. **Zoomウェビナー登録API** で参加URLを発行
5. **Gmail/SendGrid** で確認メール送信（Zoom URL ＋ カレンダー招待 ＋ LP記載の事前ヒアリング）
6. **Slack** の運営チャンネルに新規申込通知（人間が一覧把握用）
7. utm_source からJVパートナーを特定し、Notion「JV報酬集計」DBに行を追加

#### 必要なMakeシナリオ数：1

#### エラーハンドリング
- Stripe決済成功・Zoom登録失敗時：管理者にSlack通知＋手動対応リカバリー
- メール送信失敗時：再送リトライ（3回）

---

### フロー2｜ウェビナー後の個別診断申込→Calendly→Slack→事前ヒアリング

#### トリガー
Calendlyで個別診断（15分・無料）が予約された時

#### 処理ステップ
1. **Calendly** Webhook を **Make** が受信
2. Notionの「個別診断」DBに新規レコード作成
3. **Claude API** で予約者の事前ヒアリング（業務悩みTOP3＋会社情報）からカスタムデモ案を自動生成 → 講師に Slack で送付（事前準備時間を3分で済ませる）
4. **Gmail** で予約者に確認メール送信
5. 予約24時間前にリマインドメール自動送信
6. 予約2時間前に「業務素材があれば共有してください」のリマインド

#### 必要なMakeシナリオ数：1（複数トリガー対応）

---

### フロー3｜AI顧問入会→決済→オンボーディング

#### トリガー
個別診断後、講師が Notion で「成約」フラグを立てる

#### 処理ステップ
1. **Stripe** でAI顧問のサブスクリプション作成（または3か月一括前払い）
   - 月次プラン or 一括プランの選択リンクを送付
2. 決済完了で Make が起動
3. Notion「AI顧問顧客」DBに新規レコード作成（契約日・契約タイプ・第1月開始日）
4. **Slack** にユーザーを招待（共通チャンネル＋個別DMチャンネル）
5. **Calendly** で第1月の4回ミーティング枠を一括予約（経営者が選択）
6. **Notion** で個人専用ページを生成（CLAUDE.md雛形・スキル雛形・時間計測シート）
7. ウェルカムメール自動送信（事前準備リスト＋Slack招待リンク）
8. **Stripe** で次回決済日（4か月目）を自動計算しNotionに記録

#### 必要なMakeシナリオ数：1

---

### フロー4｜Slack質問→AI一次回答→人間承認→送信

#### トリガー
AI顧問顧客がSlack質問チャンネルに投稿

#### 処理ステップ
1. **Slack Bot** が質問を検知（特定の絵文字またはチャンネル限定）
2. **Claude API** で過去のFAQと顧客のCLAUDE.mdを参照して一次回答ドラフトを生成
3. ドラフトを **講師の専用Slackチャンネル** に送付
4. 講師がドラフトを30秒で確認 → 「承認」ボタンで送信、または「修正」で手動対応
5. 承認された回答が顧客のSlackに投稿される
6. 質問と回答のペアを **Notion FAQ DB** に蓄積（次回の参照精度向上）

#### 必要なMakeシナリオ数：1

#### コスト見積
- 1質問あたりClaude API利用 約¥5
- 月100質問でも ¥500 程度

---

### フロー5｜ウェビナー録画→記事＋SNSコンテンツ自動生成

#### トリガー
Zoom録画がクラウドにアップロードされた時

#### 処理ステップ
1. **Zoom** Webhook を **Make** が受信
2. **tldv** で文字起こしを取得（または Zoom 自動文字起こしを使用）
3. **Claude API** に渡して以下を一括生成：
   - note記事（2000字、章立て付き）
   - X投稿スレッド（5〜10ポスト）
   - LinkedIn投稿（500字）
   - メルマガ用サマリ（300字）
4. **Notion** の「コンテンツ下書き」DBに格納
5. **Slack** で講師に「下書き完成」通知
6. 講師が Notion で確認・微修正 → 「公開」フラグで実際の note / X / LinkedIn に投稿（手動 or Buffer等の予約投稿）

#### 必要なMakeシナリオ数：1

---

### フロー6｜JV報酬月次レポート自動生成・送付

#### トリガー
毎月末日 23:00（Make スケジュール）

#### 処理ステップ
1. Notion「JV報酬集計」DBから当月の成約データを抽出（utm_source別に集計）
2. **Claude API** で各JVパートナー宛のレポートメール本文を生成（決まったテンプレに数値を流し込み）
3. **Gmail** で各JVパートナーに自動送信
4. 同時に **Notion** の「支払い予定」DBに翌月15日の振込タスクを自動作成
5. **Slack** で講師に「JVレポート送付完了」通知

#### 必要なMakeシナリオ数：1

---

### フロー7｜CRM・LTVスコアリング（週次）

#### トリガー
毎週月曜 9:00（Make スケジュール）

#### 処理ステップ
1. Notion「AI顧問顧客」DBから全顧客の状態を取得
2. **Claude API** に以下を渡して継続兆候／離脱兆候をスコアリング：
   - 過去30日のSlack質問頻度
   - ミーティング参加率
   - 月配布スキルの利用ログ（自己申告）
3. スコアが下がった顧客を「要フォロー」フラグでNotion更新
4. **Slack** で講師に週次サマリ通知（「今週フォローすべき顧客リスト」）
5. 高スコア顧客は「法人化打診候補」として別レポートに

#### 必要なMakeシナリオ数：1

---

### フロー8｜法人提案書テンプレ自動カスタマイズ

#### トリガー
Notion で「法人化打診」フラグが立った顧客

#### 処理ステップ
1. **Make** が起動
2. **Claude API** に以下を渡す：
   - 顧客の業界・規模・痛み（Notionから抽出）
   - 法人パックの基本テンプレート
3. カスタマイズされた提案書ドラフト（Google Docs）を自動生成
4. **Slack** で講師に「提案書ドラフト完成」通知＋Google Docs URL
5. 講師が確認・修正 → 顧客に送付

#### 必要なMakeシナリオ数：1

## Slack ワークスペース設計

### チャンネル構造
- `#general` — 全体お知らせ
- `#ai_advisor_community` — AI顧問顧客全員のコミュニティチャンネル
- `#monthly_skills` — 月配布スキルの配布チャンネル
- `#group_meetings` — 月1グループ会の事前事後
- `#dm-{customer_name}` — 顧客個別チャンネル（プライバシー守秘の質問用）
- `#ops` — 運営連絡（講師＋スタッフのみ）
- `#alerts` — Make/Zapierからの自動通知

### Slack運用ルール（顧客向け配布）
- Q&Aは `#ai_advisor_community` で投稿（他の経営者にも価値があるため）
- 機密性の高い質問は `#dm-{自分の名前}` で
- 24時間以内に必ず一次回答（実際は数時間）
- 投稿時は冒頭に [質問] [報告] [雑談] のタグを付ける（自動分類用）

### Slackの自動化Bot
- 新規メンバー参加時：自動でウェルカムメッセージとオンボーディングリンク送付
- [質問]タグの投稿：フロー4を起動
- 24時間以上未回答の質問：講師にSlack DMでアラート

## Stripe 構成

### 商品設定
| 商品 | タイプ | 価格 |
|---|---|---|
| ウェビナー β | One-time | ¥10,000 |
| ウェビナー 正規 | One-time | ¥29,800 |
| AI顧問 月次 | Recurring（月次） | ¥50,000 |
| AI顧問 3か月一括 | One-time | ¥138,000 |
| AI顧問 6か月一括 | One-time | ¥270,000 |
| 法人パック | One-time | ¥600,000〜¥800,000（カスタム） |
| 法人顧問 月次 | Recurring（月次） | ¥300,000 |

### サブスク管理
- AI顧問 月次は **3か月最低継続** を契約書（メール添付PDF）で明記
- Stripeのキャンセル機能は3か月後から有効化（Customer Portalで4か月目以降選択可能）
- 3か月以内のキャンセル希望は手動対応（基本受けない）

### Webhook
- `payment_intent.succeeded` → Make経由で各種フロー起動
- `customer.subscription.deleted` → 解約処理（Slack削除＋Notion更新）
- `customer.subscription.updated` → プラン変更検知

## セキュリティ・コンプライアンス

### 機密情報の扱い
- 経営者から預かる業務素材（議事録・メール等）は **Notion の専用パスワード保護ページ** に格納
- Claude APIに送る際は、社名・個人名のマスキング処理を必須化
- Stripe以外のところにカード情報を保存しない

### バックアップ
- Notion → 週次でMarkdown / CSVエクスポート（Google Driveに自動保存）
- Slack → ProプランのData Export機能を月次で実行
- Notionテンプレ・Makeシナリオ → Gitリポジトリでバージョン管理

### NDA運用
- 入会時にNDAをSign で締結
- スタッフ採用時もNDA必須
- 顧客事例の公開は明示的な許諾後のみ
