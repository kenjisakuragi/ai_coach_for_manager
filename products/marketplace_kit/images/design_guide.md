# 画像作成ガイド｜ココナラ／ランサーズ

> ココナラとランサーズの両プラットフォームで使う画像セットを、HTMLテンプレで用意しています。
> ブラウザで開いてスクリーンショット → そのまま出品画像として使えます。

---

## 1. ファイル一覧

| ファイル | 用途 | 推奨サイズ |
|---|---|---|
| `main_image.html` | サムネイル（メイン画像） | 1080 × 720 |
| `sub_images.html` | サブ画像 6種類 | 1080 × 720（各） |

## 2. プラットフォーム別の仕様

### ココナラ
| 項目 | 仕様 |
|---|---|
| メイン画像 | 1080 × 720 推奨（最低 640 × 480） |
| サブ画像 | 最大 10枚、各 1080 × 720 推奨 |
| ファイル形式 | JPG / PNG |
| ファイルサイズ | 各 5MB以内 |
| 文字制約 | 商品の本質を伝える内容（誇大表現NG） |

### ランサーズ
| 項目 | 仕様 |
|---|---|
| サムネイル | 1280 × 720（16:9）推奨 |
| 補足画像 | 最大 5枚 |
| ファイル形式 | JPG / PNG |
| ファイルサイズ | 各 10MB以内 |

→ ランサーズ用は HTML の `width: 1080px` を `1280px` に変更すれば対応可能

## 3. スクリーンショット手順

### 方法A｜ブラウザのスクリーンショット機能（最推奨）

#### Mac
1. `main_image.html` をブラウザで開く
2. **Cmd + Shift + 4** → 範囲選択
3. 画像枠に合わせてドラッグ → 自動保存

#### Windows
1. `main_image.html` をブラウザで開く
2. **Snipping Tool**（Windows + Shift + S）を起動
3. 「四角形の領域切り取り」を選択 → 画像枠を選択

### 方法B｜ブラウザの開発者ツール

1. ブラウザで対象HTMLを開く
2. **F12**（開発者ツール）
3. **Cmd/Ctrl + Shift + P** → "Capture node screenshot" と入力
4. 該当する `<div class="thumb">` または `<div class="img">` を選択
5. ノードのスクリーンショットを撮影 → ピクセルパーフェクト

### 方法C｜スクリーンショット拡張機能
- **GoFullPage**（Chrome）：要素単位の保存可
- **FireShot**：クロス選択保存

## 5. デザイン仕様

### カラーパレット
| 用途 | 色 |
|---|---|
| 背景 | `#FFF9EE`（クリーム） |
| 背景アクセント | `#FFE9B8`（ウォームイエロー） |
| メインインク | `#2A2419`（暖かみのある黒） |
| アクセント | `#FF8C42`（オレンジ） |
| 強調 | `#FFD84D`（イエロー）、`#FFE585`（ハイライト） |
| 成功 | `#5CB85C`（グリーン） |
| 警告 | `#E55A4B`（レッド） |

### フォント
- **見出し**：Zen Maru Gothic 900（角丸ゴシック・親しみやすい）
- **本文**：Noto Sans JP 500/700/900

→ いずれも Google Fonts から自動読込

### デザイン原則
1. **手書き風の角丸**（neo-brutalism スタイル）
2. **黒い太枠＋影**（shadow-offset で立体感）
3. **マーカー風ハイライト**（重要箇所を黄色で強調）
4. **絵文字を要所で使う**（親しみやすさ）

## 6. 文字配置のルール

### サムネイルの "守るべき" レイアウト
```
[左上：バッジ]                              [右上：価格]
                                                     
                                                     
                  [中央：メインコピー]                
                                                     
                  [チェックバッジ3つ]                 
                                                     
            [下部：講師プロフィール一行]              
```

### よくある失敗パターン
- 文字が多すぎる → 1サムネ1メッセージに絞る
- 装飾過多 → 余白を残す（黄金比1:1.6で）
- 安っぽい色使い → ビビッドな赤・青は避ける

### ココナラ用調整
- メイン画像にカジュアルさを足す（絵文字・親しみ）

## 9. Canva / Figma で再現したい場合

HTMLが扱いにくい場合は、以下の方法で再現できます：

### Canva の場合
1. Canvaで「カスタムサイズ」→ 1080 × 720
2. 用意したHTMLのスクリーンショットを参考にしながら、
   Canvaの素材で再現
3. 同じカラーコード（`#2A2419` `#FF8C42` 等）を使う
4. フォントは「Zen Maru Gothic」または近い「M PLUS Rounded 1c」

### Figma の場合
1. 1080 × 720 のフレーム作成
2. HTMLのCSS値（角丸・影・色）をそのまま再現
3. テキストを編集
