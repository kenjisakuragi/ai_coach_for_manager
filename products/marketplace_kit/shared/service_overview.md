# 2時間¥30,000パッケージ｜商品設計

## このパッケージの位置づけ

**目的**：本格的なAI顧問サービス（月¥50,000・3か月コミット）に進む前の、**検証用エントリー商品**。
ココナラ・ランサーズで小ロット販売し、以下を検証する：

- 経営者・個人事業主の "Claude Code に対する反応"
- 2時間で実装→満足を作れるか
- 後段のAI顧問への引き上げが起きるか

## ターゲット顧客

### 主要ターゲット
- **個人事業主・小規模法人の代表**（一人〜10人規模）
- **副業ワーカー（経営者寄り）**
- **士業・コンサル・コーチング業**

### 心理状態
- 「ChatGPTは触ったが続かなかった」
- 「AI気になるけど何から始めればいいか分からない」
- 「数十万円のコンサルは重い、まず試したい」
- 「動画教材は途中で止まる、誰かに横で教えてほしい」

## 提供価値（コア）

> **2時間で、あなた専属のAIアシスタント "Claude Code" を立ち上げ、実業務の自動化が動き始める状態を作ります。**

**3つの成果物**：
1. ✅ あなたのPCで Claude Code が動く
2. ✅ あなた専用の取扱説明書（CLAUDE.md）が完成
3. ✅ 業務自動化スキル1〜2本が動いている

## 2時間の進行設計

| 時間 | 内容 | 成果物 |
|---|---|---|
| 0〜10分 | オリエンテーション・業務ヒアリング | 自動化対象の特定 |
| 10〜30分 | Claude Code 環境構築（一緒に） | 動作する環境 |
| 30〜50分 | CLAUDE.md（取扱説明書）作成 | 自分仕様の応答 |
| 50〜90分 | 業務自動化スキル実装①（議事録 or 朝のニュース or 下書き） | 動くスキル1本目 |
| 90〜110分 | 業務自動化スキル実装② または ハンズオン | 動くスキル2本目（任意） |
| 110〜120分 | 宿題確認＆次の一歩 | 1か月の実践計画 |

## 含まれるもの

- ✅ 2時間Zoomマンツーマン
- ✅ 当日の録画（後日復習可）
- ✅ CLAUDE.mdテンプレート（汎用版）
- ✅ スキルファイル雛形（議事録要約／朝のブリーフ／下書きから2本選択）
- ✅ 30日間のメール質問サポート（5回まで）

## 含まれないもの

- ❌ 法人向けカスタマイズ（社員研修等）
- ❌ ChatGPTやその他ツールのレクチャー
- ❌ プログラミング基礎教育

## 受講前の必要条件

- ✅ PC（Mac または Windows、現役のもの）
- ✅ Anthropic Claude Pro契約（月¥3,000程度・別途費用）
- ✅ 安定したインターネット環境
- ✅ Zoomが使える状態

## 価格設計の根拠

### なぜ¥30,000か

| ベンチマーク | 価格帯 |
|---|---|
| 経営者向け単発セミナー（オンライン） | ¥10,000〜¥50,000 |
| 個別コンサル時間単価（中級） | ¥15,000〜¥30,000/h |
| プログラミングスクール体験講座 | ¥5,000〜¥30,000 |
| Claude Code単独の市場相場 | まだ確立されていない |

→ 2時間×¥15,000＝¥30,000 がスイートスポット
→ ¥10,000は本気度フィルタ不足、¥50,000はエントリー商品として高い

### 利益構造（1件あたり）

| 項目 | 金額 |
|---|---|
| 売価 | ¥30,000 |
| ココナラ手数料（22%） | ▲¥6,600 |
| または ランサーズ手数料（5〜16%） | ▲¥1,500〜¥4,800 |
| 実工数：準備1h＋本番2h＋事後1h＝4h | - |
| 実質時間単価 | 約¥6,000/h（ココナラ）／¥6,300〜¥7,100/h（ランサーズ） |

**ココナラの方が手数料は高い**が、購入導線が経営者層に近い。両方で検証して比較する。
