## カテゴリA｜技術面・スキルレベル

### A1. 本当にプログラミング知識ゼロでも大丈夫？
はい、大丈夫です。受講者の7割は「Excelの関数も書いたことがない」レベルの方です。

Claude Codeは "コードを書く" ツールではなく、**"AIに指示を出す" ツール**です。
必要なのは、部下に指示を出すスキル＝経営者の本業。

万が一、当日の環境構築でつまずいても、画面共有しながら一緒に進めるので、
ほとんどの方が2時間以内に動かせる状態になります。

### A2. PCに詳しくないけど、何を準備すればいい？
以下だけご準備ください：

- PC（Mac または Windows、現役で使っているもの）
- Anthropic Claude Pro契約（claude.ai でPro版に登録）
- Zoomが使える状態
- インターネット接続

それ以外（Claude Codeのインストール等）は当日一緒に行います。

### A3. Mac？Windows？どっちでもいい？
どちらでも対応可能です。ただし：

- **Macの方がインストールはスムーズ**（コマンドラインが使いやすい）
- **Windowsでも問題なく動きます**（PowerShellを使います）

ご利用環境を事前にお知らせいただければ、それに合わせた手順書を当日ご用意します。

### A4. 会社支給のPCで受けたい
会社のセキュリティポリシーで管理者権限が制限されている場合、
以下のいずれかの対応になります：

- IT部門に Node.js と Claude Code CLI のインストール許可を依頼
- 個人PCで受講して、後で業務PCに展開
- 当日、代替手段（クラウド版ブラウザ）で進める

事前にメッセージでご相談ください。

## カテゴリB｜内容・進行

### B1. 2時間で何ができるようになる？
具体的には以下が達成されます：

✅ あなたのPCで Claude Code が動く環境
✅ あなた専用の「取扱説明書」（CLAUDE.md）
✅ 業務自動化スキル2本（議事録／朝のニュース／メール下書き等から選択）
✅ 1か月の実践計画

つまり、**翌日から実業務で使い始められる状態**です。

### B2. 自動化スキルはどれを選べばいい？
当日のヒアリングで、お客様の業務に最も効くものを一緒に選定します。

参考までに人気の組み合わせ：

- **経営者・代表者**：議事録要約 + メール下書き
- **コンサル・士業**：朝のブリーフ + 議事録要約
- **発信を強化したい方**：メール下書き + SNS投稿生成
- **情報収集を強化したい方**：朝のブリーフ + 議事録要約

事前ヒアリングシートでご希望を伺います。

### B3. 自分の業務に合うか分からない
購入前に、メッセージで5分ほど業務内容をヒアリングできます。

「これは合いません」と判断したら、率直にお伝えします。
合わない方に売ることは、私にとっても良くないので。

お気軽にお問い合わせください。

### B4. 当日、一緒に手を動かす感じ？それとも見るだけ？
**一緒に手を動かす** スタイルです。

私が画面共有しながら説明し、お客様が実際に自分のPCで操作します。
分からない箇所があればその場で止めて、解決してから次に進みます。

「習うより慣れる」のが、AIを業務に組み込む最短ルートです。

### B5. ChatGPTとの違いは？
最大の違いは **"記憶し続ける"** こと。

- ChatGPT：毎回ゼロから説明する必要がある
- Claude Code：あなたの会社・性格・好みを覚え続ける

例えば「議事録を要約して」と言うと：

- ChatGPTは毎回「私は経営者で、必ず判断ポイントを抽出して」と説明する必要がある
- Claude Codeは1度設定すれば、毎回同じ品質で出力される

月30時間の差は、ここから生まれます。当日のレッスンで実感していただけます。

## カテゴリC｜セキュリティ・コンプライアンス

### C1. 機密情報をAIに渡しても大丈夫？
**Anthropic社（Claudeの提供元）は、API経由で送られたデータを学習に使わない**ことを契約で明示しています。

つまり、あなたが送ったデータが他のユーザーへの応答に流用されることはありません。

ただし、念のため：

- 顧客名・社員名は仮名化する運用をお勧めします（X-社、T氏 など）
- 高度な機密情報（M&A、給与情報等）は別環境を推奨

これらの運用ルールも当日お話しします。

### C2. データはどこに保存される？
- **AIに送るデータ**：Anthropic社のサーバー（米国）。学習に使われない、保存期間限定
- **CLAUDE.md やスキルファイル**：あなたのPC上のローカルファイル
- **当日の録画**：受講者と講師のみがアクセス可能

外部に流出することはありません。

### C3. 事前ヒアリングシートで業務情報を書くのが不安
ヒアリングシートには、機密情報を書かない範囲で結構です。

「業種」「困っている業務の概要」程度で十分です。
具体的な顧客名・社員名は当日のレッスン中に仮名化して扱います。

## カテゴリD｜価格・支払い

### D1. ¥30,000は高くない？
正直にお伝えします：

- マンツーマン2時間で時間単価¥15,000
- 個別コンサルタントの相場（¥15,000〜¥30,000/h）の中央値
- 取り戻す時間が月10〜30時間として、**翌月にはペイ**

価格に納得できない場合は、ご購入をお勧めしません。
その場合は、無料コンテンツ（YouTubeの公式チュートリアル等）から始めることをお勧めします。

### D2. 領収書は出る？
ココナラ・ランサーズのシステムから電子領収書を発行できます。
法人名・宛名指定にも対応します。

### D3. 経費で落とせる？
事業のための研修費として経費計上可能です。
具体的な計上方法は、顧問税理士にご確認ください。

### D4. クレジットカード以外の支払い方法は？
ココナラ・ランサーズの規定に従います：

- **ココナラ**：クレジットカード、コンビニ、銀行振込、PayPay 等
- **ランサーズ**：クレジットカード、銀行振込

### D5. 分割払いできる？
ココナラ・ランサーズの仕様上、原則一括払いです。
クレジットカード会社のリボ払い・分割払いはご利用可能です。
