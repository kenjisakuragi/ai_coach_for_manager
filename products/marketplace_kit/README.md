## 検証KPI（出品後30日）

| 指標 | 目標値 | 判断 |
|---|---|---|
| 表示回数 | 1日10回以上 | サムネ・タイトルが効いているか |
| 問い合わせ率 | 表示の1%以上 | 訴求が刺さっているか |
| 購入率 | 問い合わせの30%以上 | 信頼形成できているか |
| 月間販売数 | 月3〜5件 | 軌道に乗ったか |
| レビュー★ | 4.5以上 | 顧客満足度 |
| AI顧問引き上げ | 月1件 | バックエンド転換 |

→ 30日でこれらを下回る場合、サムネ／タイトル／本文をA/Bテストで改善

## 設計の要点

### なぜ¥30,000か
- 個別コンサル時間単価 ¥15,000/h × 2時間
- ¥10,000は冷やかし排除不足、¥50,000はエントリーには高い
- ココナラ手数料22%差し引いても、時間単価約¥6,000/h確保

### なぜ2時間か
- 環境構築 + CLAUDE.md + スキル2本 = 物理的な時間として2時間が下限
- 4時間にすると顧客の集中力が切れる
- マンツーマンで2時間 = 顧客の時間投資としても許容範囲

### なぜココナラとランサーズの両方か
- 客層が微妙に違う（個人事業主寄り vs 法人寄り）
- 手数料・操作性も違う（A/Bテスト的に両方試す）
- 1か月ずつ運用 → どちらが効率的か判断

## ココナラ vs ランサーズ｜どちらを優先？

両方同時に出品して、30日後に判断する案：

| 項目 | ココナラ | ランサーズ |
|---|---|---|
| 客層 | 個人事業主寄り | 法人代表者寄り |
| 手数料 | 22%（高い） | 5〜16%（安め） |
| 検索性 | 直感的 | やや難しい |
| 競合の多さ | 多い | やや少ない |
| AI顧問への引き上げ親和性 | 中 | 高 |

→ 私の予想：**ランサーズの方が AI顧問への引き上げ確度が高い** ですが、ココナラの方が **販売量は出る** 可能性があります。

両方で30日試して数字で判断するのが最も合理的です。

## 注意事項

- 価格は税込表示（プラットフォームの規定）
- 法人向け（社員研修等）は別商品扱い、混ぜない
- 競合との価格比較を煽らない（プラットフォーム規約）
- 誇大表現NG（「絶対」「100%」「業界No.1」等）
- レビュー誘導は丁寧に（強要にならないように）

## 困ったときは

- 出品が拒否された → カテゴリ変更、文言調整
- 表示されない → SEO対応（タグ・カテゴリ最適化）
- 問い合わせ来るけど成約しない → 本文の "向いていない方" 訴求を強化
- レビュー★が低い → 当日のサービス品質を見直す（録画を客観視）
