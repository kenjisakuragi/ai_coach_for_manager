## Googleスライドへ変換する手順（30秒）

### 方法A｜ドラッグ&ドロップでアップロード（最速）

1. ブラウザで [Google Drive](https://drive.google.com) を開く
2. ダウンロードした `slides.pptx` を **Driveの画面にドラッグ&ドロップ**
3. アップロード完了後、ファイルを **右クリック** → 「アプリで開く」 → 「Googleスライド」
4. 開いた状態で「ファイル」 → 「Googleスライドとして保存」

→ Googleスライドの形式に変換されたファイルが作成されます

### 方法B｜Googleスライドから直接インポート

1. [Googleスライド](https://slides.google.com) を開く
2. 「空白のプレゼンテーション」を作成
3. 「ファイル」 → 「インポート」 → 「アップロード」 タブ
4. `slides.pptx` を選択 → アップロード
5. 「すべてのスライドをインポート」を選択

### 方法C｜共有時に自動変換（推奨）

1. Drive にアップロード
2. **右クリック** → 「コピーを送信」 → 「Googleスライド」
3. これで Drive 上に Googleスライド版とPPTX版の両方が保存されます

## 変換後の確認ポイント

PowerPoint → Googleスライド変換後、以下を確認してください：

### ✅ 高い確率でそのまま動くもの
- テキスト・見出し
- 色・背景
- 角丸シェイプ
- 表
- ページ番号

### ⚠️ 確認推奨（フォントが違うと崩れる可能性）
- **日本語フォント**：Google Slidesでは "Yu Gothic UI" がない場合があるので、"Noto Sans JP" や "M PLUS Rounded 1c" に置換すると見栄えが整います
- **絵文字（📝📰🔍📱など）**：Google環境でも表示されますが、デザインがOSにより異なります
- **マーカーハイライト**：背景色が一部抜ける可能性。気になる箇所は手動で背景塗りで再現

### よくある修正項目
1. フォント置換（一括）：「すべて選択」→ フォント変更で全スライドに適用
2. 絵文字の大きさ：1段階上げると視認性アップ
3. ページ番号の位置調整：右上のレイアウトが微妙にずれる場合あり

## 修正版を作りたい場合

このPPTXは `build_pptx.js`（同フォルダ）から生成しています。

スクリプトを編集して再生成すれば、いつでも更新版を作成できます：

```bash
cd products/webinar
node build_pptx.js
# → slides.pptx が再生成される
```

主なカスタマイズ箇所：
- カラーパレット（ファイル冒頭の `C` オブジェクト）
- 各スライドのテキスト・配置
- フォント設定（`FONT` 変数）

## 補足｜なぜこの構成にしたか

- **35スライドで120分** = 1スライドあたり平均3.4分
- **大きな数字（30、20-25、5万円）を強調**して記憶に残す
- **Before/After比較**を多用して "変化" を可視化
- **チャット呼びかけスライド**（オレンジ背景）でインタラクションの場を明示
- **セクション区切り（PART 1/2/3）**で進行を分かりやすく
- **CTA付きスライド**で個別診断への動線を強化

満足度を上げるために、以下を意識：
- 1スライド1メッセージ（情報過多にしない）
- 経営者の "あるある" に共感を引き出す
- 数字の根拠を明確化
- 売り込み感を抑え（最後の20分だけ）
- 質問・回答の双方向性を確保
