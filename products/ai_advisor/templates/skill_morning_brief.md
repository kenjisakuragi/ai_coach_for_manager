# 朝のブリーフィングスキル（morning_brief.md）

> 朝のニュースチェック15〜20分を、1分で終わらせるスキル。
> `~/AI_Chief_of_Staff/skills/morning_brief.md` に配置。

---

## 目的
今朝の業界動向・自社への影響・今日の判断材料を **1分** で生成する。

## 入力
- 監視対象URL（CLAUDE.mdに記載済み）
- またはキーワード検索（「AI」「〇〇業界」など）
- 当日の予定（オプション、カレンダーから取得 or 手動入力）

## 出力フォーマット

### 🌅 今朝の3行サマリ
業界全体の流れを30字×3行で、見出し的に。

### 📊 業界ニュース 重要度トップ3
1. **[★★★]** [タイトル] — [なぜ重要か30字]
   - リンク：[URL]
2. **[★★]** [タイトル] — [...]
3. **[★]** [タイトル] — [...]

### 🎯 私の会社／競合への影響
- **自社**：（ポジティブ／ネガティブ／無関係）
   - 推測ベースの場合は [推測] タグ
- **競合（A-社、B-社）**：（動きあれば言及）

### ⚡ 今日の判断に効く1件
1つだけ。本日のMTGや決断と紐づけて。
> 例：「14:00の投資家MTGで、A-社の動向を先回りして触れる材料になります」

### 🔮 今週の注目事項（オプション）
- 来週以降に控えているイベント・発表
- 中期的な伏線として

## トーン・制約

- 簡潔。です・ます調。
- 全体でA4半分以内（読了1分以内）。
- 重要度は ★ の数で示す（★★★が最高）。
- 推測は [推測] タグ、確認待ちは [未確認] タグ。
- 私が興味ない話題（CLAUDE.mdの「興味のないテーマ」参照）はスキップ。
- ニュースを **"経営者目線"** で評価。"面白さ" ではなく "意味" で。

## 使い方の例

### Claude Code でのコマンド例
```bash
claude
> skills/morning_brief.md を実行して
```

または、特定テーマで深掘り：
```bash
> skills/morning_brief.md を使って、AI規制関連だけ深掘りして
```

### 期待される動き
1. CLAUDE.md から監視対象URL・キーワード・私の興味を把握
2. WebFetch で各URLから最新記事を取得
3. 重要度評価（経営者視点）
4. 自社・競合への影響分析
5. 出力

## カスタマイズのヒント

### 曜日別のフォーマット
- **月曜**：先週末からの変化を重点的に
- **金曜**：来週のイベント・発表予定を加える

スキルを曜日別に分けることも可能：
- `morning_brief_monday.md`
- `morning_brief_friday.md`

### 投資家／株主向け情報の追加
公開企業の場合は：
```markdown
### 📈 株式市場の動き
- 自社株価：[前日比]
- 競合株価：[A-社, B-社]
- セクター全体：[トレンド]
```

### 顧客動向の追加
重要顧客の最新情報も拾いたい場合：
```markdown
### 🤝 主要顧客の動向
- X-社：[ニュース・動き]
- Y-社：[...]
```

## 監視対象URL（CLAUDE.mdから参照）

CLAUDE.md の「朝のブリーフ・対象」セクションを参照。
ここに直接書くこともできるが、CLAUDE.md にまとめた方が他のスキルからも参照可能。

## トラブルシューティング

### URLからニュースが取得できない
- ログイン必須サイトはアクセス不可（→ メルマガ等の別経路で代替）
- レイトリミット → 取得対象を減らす
- WebFetch機能が有効か確認

### 重要度の判定が曖昧
- 「重要度」の定義を明示
- 「★★★：今日の経営判断に直接影響、★★：今週中に判断必要、★：来月以降の参考」

### 朝起きるたびに同じニュースが出る
- 「24時間以内のニュース限定」という制約を追加
- 既読フラグの仕組みを別途実装（応用編）

### 自社／競合の影響分析が浅い
- CLAUDE.md に競合と自社の差別化ポイントを詳細に書く
- 「影響分析時は、必ず数値・事業領域・顧客への影響に分けて評価」と指示
