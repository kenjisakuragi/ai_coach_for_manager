# 意思決定の壁打ちプロンプト集

> 第3回で扱う「意思決定支援」の3つのプロンプトテンプレ。
> Claude を経営判断の壁打ち相手として使うための定型文。

---

## 型1｜論点整理型

### こういう時に使う
- 情報が散らかっていて、何から考えればいいか分からない
- 関係者が多くて、論点が見えない
- 直感的な判断はあるが、言語化できない

### プロンプト

```
以下のテーマで決断する必要があります。

【現状】
[3〜5行で状況を説明]

【関係する人・組織】
- A: 〇〇
- B: 〇〇

【私が今考えている選択肢】
（あれば。なくてもOK）
- 案1: 〇〇
- 案2: 〇〇

【質問】
1. 論点を3つに絞り、それぞれに対する選択肢を整理してください。
2. 私が見落としている観点があれば指摘してください。
3. 各選択肢のメリット・デメリットを並べてください。

最終決定はしません。判断材料の整理だけしてください。
```

---

## 型2｜賛成・反対両論型

### こういう時に使う
- 自分の中で結論が出ている
- でも本当にそれでいいか不安
- 反対意見を事前にシミュレーションしたい

### プロンプト

```
私は今、以下の決断をしようとしています。

【決断の内容】
[1〜3行で具体的に]

【決断に至った理由】
[3〜5行]

【質問】
1. この決断に強く反対する人がいるとします。最も論理的で説得力のある反対意見を3つ書いてください。
2. それに対する私の再反論案も提示してください。
3. もし反対意見の方が論理的に優れている場合は、率直にそう指摘してください。

私は反対意見を **歓迎します** 。本気で反対してください。
```

### バリエーション

#### 「未来の自分」からの反対
```
3年後の私が、この決断を振り返って後悔しているとします。
何が原因で後悔していると思いますか？最も可能性の高い理由を3つ。
```

#### 「業界外の専門家」からの視点
```
別業界（例：医療、教育、軍事）の専門家がこの決断を見たら、
どんな観点から疑問を投げかけてくると思いますか？
```

---

## 型3｜影響先洗い出し型

### こういう時に使う
- 重要な決定の直前
- 関係者が多い
- 想定外の影響を避けたい

### プロンプト

```
私は以下の決定をします。

【決定の内容】
[3行以内で]

【質問】
この決定で、以下のステークホルダーごとに影響を整理してください：

1. 顧客（既存・新規・潜在）
2. 社員（直接影響を受ける部署・受けない部署）
3. 取引先・パートナー
4. 株主・投資家
5. 競合
6. 自分自身（時間、メンタル、信用）

それぞれに、ポジティブ／ネガティブ／要対応 の3区分で具体的に。

特に、**私が今気づいていない影響先** があれば指摘してください。
```

---

## 応用編｜複数の型を連続して使う

決定の重要度が高い時は、3つを順に使う：

### Step 1: 論点整理型 で土俵を整える
↓
### Step 2: 賛成・反対両論型 で自分の決断を試す
↓
### Step 3: 影響先洗い出し型 で漏れを防ぐ

→ これで30分〜1時間。
→ 経営者の人生を変える可能性のある決断は、これくらい時間をかける価値がある。

---

## 壁打ちの原則

### Claudeに期待すること
- 論点の整理
- 視点の提供
- 反対意見のシミュレーション
- 漏れの指摘

### Claudeに期待しないこと
- **答えを出すこと**（最終決定は社長の仕事）
- 感情的な共感
- 法的・税務的な確定的判断（専門家へ）
- 機密性の高い社外秘情報の処理（CLAUDE.mdの仮名化ルール厳守）

---

## トラブルシューティング

### Claudeが結論を断言してくる
プロンプトに以下を追加：
> 「答えを出さないでください。判断材料の整理だけしてください。」

### 反対意見が弱い／表面的
プロンプトに以下を追加：
> 「最も賢い反対者になりきってください。本気で反対してください。」

### 出力が長すぎ
> 「各観点 3行以内で。全体A4半分以内。」

### 自分の業界・文脈に合わない一般論的な回答
- CLAUDE.md の充実度が原因
- 業界特有の用語・慣習・規制を CLAUDE.md に追記

## 蓄積のすすめ

壁打ちした記録は `decisions/` ディレクトリに蓄積：

```
~/AI_Chief_of_Staff/
├── CLAUDE.md
├── skills/
└── decisions/
    ├── 2026-05-15_新規プロダクト責任者選定.md
    ├── 2026-05-20_Q3予算修正.md
    └── ...
```

各ファイルに：
- 状況
- 検討した選択肢
- 最終決定
- 半年後／1年後の振り返り（後で追記）

→ 1年蓄積すると、自分の **判断の癖** が見えてくる
→ Claudeに「過去の意思決定パターンを分析して」と依頼できるようになる
