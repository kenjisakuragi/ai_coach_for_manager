# 議事録要約スキル（meeting_summary.md）

> このファイルは、Claude Code に「議事録要約」をやらせるための指示書です。
> `~/AI_Chief_of_Staff/skills/meeting_summary.md` に配置してください。

---

## 目的
会議の文字起こしから、決定事項・宿題・私の判断ポイントを **90秒で** 抽出する。

## 入力
- 会議の文字起こしテキスト（.txt / .md）
- または録画ファイル（事前に文字起こしツールで変換）

## 出力フォーマット

### 📋 会議の概要
（30字以内で：いつ・誰と・何の会議だったか）

### ✅ 決定事項（経営判断のみ）
最終確定したものだけ列挙。検討中・案レベルは含めない。
- 1
- 2

### 📝 次のアクション

| 担当 | アクション | 期限 |
|---|---|---|
|  |  |  |

担当が不明な場合は [未定] と明記。

### 💭 論点として残っているもの
未解決のまま次回に持ち越されたテーマ。
- 1
- 2

### ⚡ 〇〇さん（私）が次に判断すべきこと
最重要セクション。私が次回までに自分で決めなければならないこと。
- 1
- 2

### 🔍 補足・気になる発言
（オプション）特定の発言で気になるもの、後で深掘りしたい論点があれば。

## トーン・制約
- 簡潔。です・ます調。
- 全体でA4半分以内。
- 推測には [推測] タグを付ける。
- 数字や日付は必ず原文ママ。
- 参加者の発言の真意が不明な場合は、無理に要約しない（[要確認] とする）。
- 個人名は CLAUDE.md の仮名化ルールに従う。

## 使い方の例

### Claude Code でのコマンド例
```bash
claude
> skills/meeting_summary.md を使って、 inputs/役員会_20260515.txt を要約して
```

### 期待される動き
1. CLAUDE.md を読み込み（私の好み・役割を把握）
2. このスキルファイルを読み込み（フォーマット・トーンを把握）
3. 入力ファイルを読み込み
4. 出力を生成

## カスタマイズのヒント

### 議事録のタイプ別カスタマイズ
- **役員会用**：「決定事項」と「私が判断すべきこと」を充実
- **1on1用**：相手の感情・モチベーションも観察
- **顧客MTG用**：「相手のニーズ」と「次の打ち手」を明確化

タイプ別にスキルファイルを分けるのも有効：
- `meeting_summary_board.md`（役員会用）
- `meeting_summary_1on1.md`（1on1用）
- `meeting_summary_client.md`（顧客MTG用）

## トラブルシューティング

### 「決定事項」と「アクション」の区別が曖昧
→ スキルに「決定事項は会社方針として確定したもの。アクションはそれを実行するためのタスク」と明記

### 会議参加者が多くて、誰の発言か追えない
→ 入力時に発言者ラベルが付いた文字起こしを使う（tldv等のツール）

### 出力が長すぎる
→ 「最大A4半分」のルールを強調、不要なセクションは削除指示
