# 業務棚卸しシート

> 第1回セッションで使用。経営者の業務を A/B/C に分類し、自動化対象を絞り込む。
> Notion・スプレッドシート・紙、どの形式でもOK。

---

## ステップ1｜直近1週間の業務を全部書き出す

時間ログから、または記憶を頼りに。
| 業務名 | 頻度（日／週／月） | 1回の所要時間 | 月間合計時間 |
|---|---|---|---|
| 例：役員会議事録の整理 | 週1回 | 30分 | 約2時間 |
| 例：朝のニュースチェック | 毎日 | 15分 | 約7.5時間 |
| 例：取引先メール返信 | 毎日 | 計60分 | 約20時間 |
| ... | | | |

→ 最低15項目、できれば20項目を出す

---

## ステップ2｜A/B/C 分類

各業務を以下に振り分け：

### A：自分にしかできない（触らない）
- 戦略的な意思決定
- 重要な対人交渉（最終契約等）
- 投資判断
- 役員人事

→ A群は **絶対に自動化しない**。経営者の本業。

### B：自分じゃなくてもいい（自動化候補）
- 議事録の整理
- 情報収集・要約
- 下書き作成
- 定型メール返信
- スケジュール調整
- 数字の集計・レポート

→ B群が **自動化のメインターゲット**

### C：そもそもやらなくていい（廃止候補）
- 惰性で続けている業務
- 効果が出ていないルーティン
- 過剰な報告・確認

→ C群は **AIではなく "やめる"** 判断

---

## ステップ3｜自動化対象トップ3を決める

B群の中から、以下の基準で3つ選定：

### 選定基準
1. **頻度が高い**（週1以上）
2. **時間がかかる**（1回30分以上 or 月合計5時間以上）
3. **判断不要**（自分の独自判断が深く必要でない）
4. **再現性が高い**（毎回似たパターン）

### 自動化対象トップ3

| 順位 | 業務 | 月時間 | 想定スキル名 |
|---|---|---|---|
| 1 |  |  | meeting_summary.md |
| 2 |  |  | morning_brief.md |
| 3 |  |  | drafter.md |

→ これが第2回で実装する3本のスキルの対象

## ステップ5｜全体まとめ

### 現状
- A群（経営判断）：月 〇〇 時間
- B群（自動化候補）：月 〇〇 時間
- C群（廃止候補）：月 〇〇 時間
- **合計**：月 〇〇 時間

### 目標
- 1か月後：B群の自動化で月 〇〇 時間取り戻す
- 3か月後：B群の追加自動化＋C群の廃止で月 〇〇 時間取り戻す
- 6か月後：本来の経営判断（A群）に **月 〇〇 時間** 集中できる状態

## ヒアリングのコツ（講師用）

### B群を抽出する質問
- 「これ、誰かに頼むとしたらどう説明しますか？」
- 「同じことを部下にやらせるとしたら、何を伝えますか？」
- 「これをやらないと、何が起きますか？」（重要度の確認）

### C群を抽出する質問
- 「これ、本当にやる必要ありますか？」
- 「やめたらどうなりますか？」
- 「3年前から続けている理由は？」

### A群を確認する質問
- 「これは絶対あなたじゃないとダメですよね？」
- 「他の経営者でこれを部下に任せている人を知っていますか？」
- 「本当に？」（A群を絞り込むため、しつこく確認する）

→ 多くの経営者は、最初に B・C群を A群と勘違いしている。
→ 「絶対自分じゃないとダメ」と思っているものの 5〜7割は実は B群

---

## 棚卸し後のアクション

1. **明日から**：C群を1つやめる
2. **来週まで**：B群トップ3を Slack で共有（業務素材を講師に送る）
3. **1か月後**：B群トップ3が自動化された状態
4. **3か月後**：B群を5〜7つ自動化、C群は半数廃止
