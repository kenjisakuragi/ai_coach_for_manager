# 3つの柱｜時間削減・意思決定支援・見える化

## 柱① 時間削減｜雑務を消す

### 解決する問題
スモールビジネスオーナーは、月30〜60時間を以下の "雑務" に奪われている：

- 議事録づくり
- 朝のニュース・情報収集
- メール・SNSの下書き
- スケジュール調整
- 経費精算・請求書処理
- フォローアップ連絡

### 提供する価値
**「自分じゃなくてもいい仕事を、AIに渡す」**

これらを Claude Code に "型" として登録することで、以下が実現：
- 1業務あたりの所要時間を **80〜95%削減**
- 品質は維持または向上（疲れによる質低下がない）
- 24時間いつでも実行可能

### 期待される効果
**月20〜40時間の取り戻し**（3か月後の継続実装で60時間到達も可）

### 該当する業務カテゴリ
- A. 朝の業務
- B. 会議運営
- E. 発信・マーケティング
- F. 経理・事務（軽め）

→ 詳細は `03_target_workflows.md`

## 柱② 意思決定支援｜判断材料を整える

### 解決する問題
スモールビジネスオーナーは、判断の連続を **1人で** 抱えている：

- 「これ、本当に正しい判断か？」
- 「見落としている観点はないか？」
- 「壁打ち相手がいない」
- 「孤独な経営判断」

### 提供する価値
**「経営者の隣で、論点を整理する役割をAIが担う」**

Claude Code を以下の3つのモードで使えるようにする：

#### 論点整理モード
散らかった情報から、判断すべきポイントを3つに絞る

#### 賛成・反対両論モード
自分の決断に、強く反対する人の論理をAIが提示

#### 影響先洗い出しモード
この決定が誰に何の影響を与えるかを網羅

### 期待される効果
- **判断の質が上がる**（見落とし防止）
- **判断スピードが上がる**（5分で論点整理）
- **孤独感の軽減**（壁打ち相手の確保）

### 該当する業務カテゴリ
- H. 意思決定（壁打ち）
- D. 営業・問い合わせ対応（提案判断）
- G. 採用・人事（候補者評価）

→ 詳細は `03_target_workflows.md`

## 柱③ 見える化｜属人化を解消する

### 解決する問題
スモールビジネスオーナーの脳内に蓄積された情報は、**ほぼ書き出されていない**：

- 「あのクライアント、誰が担当だっけ」
- 「3か月前、何を約束したっけ」
- 「過去の見積もり、どこ？」
- 「この顧客は何が地雷だっけ」

→ 漏れが起きると信用問題。引き継ぎ不可能。

### 提供する価値
**「経営者の頭の中を、引き継ぎ可能な形に変える」**

具体的には：
- クライアント情報の構造化（仮名化＋テンプレ化）
- 案件・プロジェクト情報の集約
- 人脈・キーマンの記録
- 過去の意思決定ログ

これらをすべて Claude Code から参照できる状態にする。

### 期待される効果
- **検索10分が消える**（過去メール掘り起こしゼロ）
- **引き継ぎ可能な状態**（後継者・スタッフ育成）
- **漏れ・忘れの撲滅**（信用維持）

### 該当する業務カテゴリ
- C. 顧客・案件管理
- D. 営業（過去のやり取り参照）
- G. 採用・人事

→ 詳細は `03_target_workflows.md`

## 大企業向け動画との違い

YouTube動画では4つ目の柱として「シグナル検知」が挙げられていますが、
スモールビジネス（30人以下）では**経営者が直接見えるため、シグナル検知は不要**です。

| 柱 | 大企業（200人〜） | スモールビジネス（〜30人） |
|---|---|---|
| 時間削減 | ◎ | ◎（最重要） |
| 意思決定支援 | ◎ | ○ |
| シグナル検知 | ◎ | △（不要） |
| 見える化 | △ | ◎（追加した） |

スモールビジネスの本当の課題は「自分の頭の中が見える化されていないこと」。
社員が少ないからこそ、経営者の脳内資産が文字通り会社の資産。

## 3本柱の優先順位

### 第1優先：時間削減
- 効果が即座に出る（1日で実感）
- 数字で説明できる（"月10時間削減"）
- ROIが明確
- ✅ **第1月で必ず体感を作る**

### 第2優先：見える化
- 中期的に効く（蓄積するほど価値が出る）
- 引き継ぎ・組織化への布石
- ✅ **第2月から構築開始**

### 第3優先：意思決定支援
- 高度な使いこなしが必要
- 経営者の "壁打ちスタイル" を見つける必要
- ✅ **第2-3月で習熟**

## 3か月の組み立て方

### 第1月｜時間削減フェーズ
**「目に見える時間を取り戻す」**
- 議事録自動化
- 朝のブリーフィング
- メール下書き
- コンテンツ展開

→ この月の終わりに「月15-20時間取り戻した」体感

### 第2月｜見える化フェーズ
**「頭の中を整理する」**
- クライアント情報構造化
- 案件・プロジェクト集約
- 過去のやり取り検索
- KPI簡易ダッシュボード

→ この月の終わりに「自分が休んでも回せる入り口」体感

### 第3月｜意思決定支援フェーズ＋運用設計
**「判断の質を上げる」**
- 壁打ちフロー確立
- 採用・営業の半自動化
- フィードバックループ設計
- 4か月目以降の運用ルール

→ この月の終わりに「自分はAIを設計できる経営者」自己認識
