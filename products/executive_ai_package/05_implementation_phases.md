## Day 0｜キックオフ・夢からの逆算インタビュー（2時間）

### 目的
動画でも強調されていた **「夢からの逆算」** を実施。
「3か月後にどうありたいか」を経営者と深く言語化する。

### アジェンダ
| 時間 | 内容 |
|---|---|
| 0〜20分 | 経営者の現状ヒアリング（業務時間配分） |
| 20〜40分 | "3か月後にこうありたい" を言語化 |
| 40〜60分 | "1年後にこうありたい" 中期ビジョン |
| 60〜80分 | 業務分類（A/B/C：触らない／自動化／廃止） |
| 80〜100分 | 第1月の自動化対象トップ3を確定 |
| 100〜120分 | 環境構築の事前準備とスケジュール |

### 必ず聞く質問
1. 「いま、自分でやっている仕事で、本当は誰かに任せたいものは？」
2. 「3か月後、自由になった時間で何をしたいですか？」
3. 「この1年で経営判断を間違えた瞬間、何が原因でしたか？」
4. 「秘書がいたら、最初に何を頼みますか？」
5. 「あなたが3日休んだら、会社は回りますか？」

### 成果物
- 「3か月後の理想像」ドキュメント（A4 1枚）
- 業務時間配分の現状把握
- 第1月で自動化する3-4業務の確定
- CLAUDE.md v0（経営者の好み・経営理念）

## フィードバックループの仕組み（動画の重要ポイント）

動画で強調されていた「**8割はフィードバックの繰り返し**」を3か月の中で確実に実装します。

### 週次フィードバック（毎週月曜30分）
- 先週使ったスキル・回数・満足度
- 「もう少しこうして欲しかった」のメモ共有
- スキルファイルの即時修正
- 来週試したいことの確認

### 月次振り返り（月末60分）
- 累計時間削減の集計
- スキル別の利用状況
- 改善・廃止判断
- 次月のテーマ調整

### 経営者へのフィードバックトレーニング
3か月の中で、経営者本人が **AI に改善要望を伝える** スキルを習得：
- 「ここをこう変えて欲しい」
- 「次回からはこういう情報も含めて」
- 「このトーンは違う、もっと〇〇に」

→ 卒業時には経営者が自分でAIを進化させられる状態に。

## 経営者の負担（時間コミットメント）

### 必須（合計24時間／3か月）
- 週1回 90分セッション × 12回 = **18時間**
- 週1回 30分振り返り × 12回 = **6時間**

### 任意・宿題（合計15-20時間／3か月）
- 業務素材の整備（クライアント情報入力等）
- スキルを毎日使う（=既存業務の代替）

### 「忙しい経営者でも続けられる」設計
- セッションは平日夜・休日も対応
- 録画OK（後で見返せる）
- Slack質問は24時間以内回答
- 1週やれない週があってもキャッチアップ可能

## "夢からの逆算" の実例

YouTube動画の経営者の例：
- 夢：「朝6:30に起きたら、その日のスケジュール・準備不足のフィードバックまで完了している」
- 逆算：Slackボット + Claude Code + カレンダー連携 + 議事録分析

スモールビジネスオーナーの例：
- 夢：「自分が3日休んでも、クライアント対応が漏れない」
- 逆算：Notion クライアントDB + Claude Code 検索 + 過去履歴の自動参照

→ 経営者ごとに "夢" が違うので、Day 0 で必ずヒアリング。
→ そこから3か月の実装を逆算する。
