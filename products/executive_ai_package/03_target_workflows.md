# ターゲット業務カタログ｜8カテゴリ × インパクト評価

スモールビジネスオーナーの業務を8カテゴリに分類し、AI導入のインパクトを評価しました。

---

## 全体マップ｜どこから手をつけるべきか

| カテゴリ | 月時間 | 自動化容易性 | 所属する柱 | 優先度 |
|---|---|---|---|---|
| **A. 朝の準備** | 6-10h | ★★★ | 時間削減 | ★★★ |
| **B. 会議・打ち合わせ** | 8-15h | ★★★ | 時間削減 | ★★★ |
| **C. 顧客・案件管理** | 10-15h | ★★ | 見える化 | ★★★ |
| **D. 営業・問い合わせ対応** | 10-20h | ★★ | 時間削減＋意思決定 | ★★ |
| **E. 発信・マーケティング** | 5-15h | ★★★ | 時間削減 | ★★ |
| **F. 経理・事務** | 5-10h | ★★ | 時間削減 | ★ |
| **G. 採用・人事** | 3-8h | ★★ | 見える化＋意思決定 | ★ |
| **H. 意思決定（壁打ち）** | 3-10h | ★★ | 意思決定支援 | ★★ |

**合計**: 月50-103時間が雑務に。ここから30-60時間取り戻すのが目標。

## A. 朝の準備｜月6-10時間

### 含まれる業務
- A1. ニュース・業界動向チェック
- A2. メール・Slack・LINEの未読処理
- A3. 当日の予定・優先順位確認
- A4. 重要な問い合わせの一次仕分け

### 痛み
- 1日の "脳の起動" に毎朝15-20分
- 情報過多で頭が散らかる
- 重要な判断材料が他の情報に埋もれる

### 自動化の効果
**月6-10時間 → 月1時間以下**

### 適用する Claude Code スキル
- `morning_brief.md`：朝のブリーフィング（業界＋自社影響）
- `morning_decisions.md`：今日の判断材料の整理
- `inbox_triage.md`：メール・Slackの優先順位仕分け

### スモールビジネス特有の調整
- メールが少ない場合：個別件名で重要度判定
- LINE/Messengerに散らばる：転記スキル併用
- 業界ニュースが英語中心の業界：自動翻訳組み込み

---

## B. 会議・打ち合わせ｜月8-15時間

### 含まれる業務
- B1. 会議の事前準備（資料・論点）
- B2. 議事録作成
- B3. 決定事項の関係者通知
- B4. フォローアップアクションの管理
- B5. 1on1記録の蓄積

### 痛み
- 議事録に毎回30分（週5会議で月10時間）
- 決定したことが実行されない
- 過去の会議で何を話したか思い出せない

### 自動化の効果
**月8-15時間 → 月1-2時間**

### 適用する Claude Code スキル
- `meeting_summary.md`：議事録要約（決定事項＋宿題＋判断ポイント）
- `meeting_prep.md`：会議の事前資料・論点準備
- `1on1_log.md`：1on1の蓄積と次回の話題提案

### スモールビジネス特有の調整
- 録音→文字起こしツール（Whisper等）の併用設定
- カレンダー連携で自動議事録振り分け
- スタッフへの自動通知（Slackボット化）

---

## C. 顧客・案件管理｜月10-15時間

### 含まれる業務
- C1. クライアント情報の検索・参照
- C2. 過去のやり取り・約束の確認
- C3. 案件・プロジェクトの状態管理
- C4. 顧客への定期的な連絡（年賀状的な）
- C5. CRM入力・更新

### 痛み
- 「あの担当、誰だっけ」を毎週繰り返す
- 過去メールを掘り返すのに10分
- 漏れたら信用問題
- CRM入力が面倒で運用されない

### 自動化の効果
**月10-15時間 → 月2時間**

### 適用する Claude Code スキル
- `clients_overview.md`：クライアント基本情報の構造化
- `clients_history.md`：やり取り履歴の集約
- `clients_next_actions.md`：次のアクション管理
- `mail_to_crm.md`：メール→CRM自動転記

### スモールビジネス特有の調整
- 高機能CRM（Salesforce等）不要、Notion or スプレッドシート連携でOK
- 仮名化（X-社、Y-社）で機密性確保
- 過去メールの一括取り込み（Gmail/Outlook）

---

## D. 営業・問い合わせ対応｜月10-20時間

### 含まれる業務
- D1. 問い合わせメールへの一次返信
- D2. 提案書・見積書の下書き
- D3. 商談後のフォローアップ
- D4. 既存顧客への定期営業
- D5. 失注分析

### 痛み
- 提案書を毎回1から書いている
- 問い合わせ対応で集中業務が中断
- 失注した理由を後から分析する暇がない

### 自動化の効果
**月10-20時間 → 月3-5時間**

### 適用する Claude Code スキル
- `inquiry_response.md`：問い合わせ対応ドラフト
- `proposal_drafter.md`：提案書下書き（過去案件参照）
- `quote_drafter.md`：見積書下書き
- `followup_email.md`：商談後のフォロー
- `loss_analysis.md`：失注パターン分析

### スモールビジネス特有の調整
- 個別カスタマイズが多い → スキルに事例3-5本を取り込む
- 価格交渉のシミュレーション機能
- 顧客タイプ別のテンプレート分岐

## E. 発信・マーケティング｜月5-15時間

### 含まれる業務
- E1. ブログ・noteの記事執筆
- E2. SNS投稿（X、LinkedIn、Instagram）
- E3. メルマガ作成
- E4. Podcast/動画→記事化
- E5. プレスリリース下書き

### 痛み
- 記事化に2-3時間かかると思って後回し
- 気づくと2か月発信してない
- "発信したいけど時間がない" を繰り返す

### 自動化の効果
**月5-15時間 → 月1-3時間**（しかも発信頻度が増える）

### 適用する Claude Code スキル
- `content_pipeline.md`：1素材→4種展開（note/X/LinkedIn/社内サマリ）
- `mailmagazine.md`：メルマガ自動下書き
- `press_release.md`：プレスリリース下書き
- `seo_optimizer.md`：SEO観点の調整

### スモールビジネス特有の調整
- 過去投稿のトーン参照（5-10本）
- "発信NG"な情報のリスト化
- 月間発信カレンダーの自動生成

## F. 経理・事務｜月5-10時間

### 含まれる業務
- F1. 領収書・請求書の整理

- F3. 経費精算
- F4. 顧問税理士へのデータ提供

### 自動化の効果
**月5-10時間 → 月1-2時間**

### 適用する Claude Code スキル
- `monthly_report.md`：月次サマリの自動生成

- `expense_summary.md`：経費の集計・カテゴリ分類
- `tax_prep.md`：税理士への送付資料整理

### スモールビジネス特有の調整
- freee/MFクラウド等のSaaS連携
- 個人事業主の場合はシンプル化（青色申告サポート）
- インボイス対応

## G. 採用・人事｜月3-8時間

### 含まれる業務
- G1. 求人原稿の作成
- G2. 応募者の一次スクリーニング
- G3. 面接質問の設計
- G4. 候補者評価の言語化
- G5. オンボーディング資料

### 痛み
- 求人を出すたびに1から書いている
- 面接後の評価が感覚的
- 採用基準がブレる

### 自動化の効果
**月3-8時間 → 月1時間**（しかも判断の質が上がる）

### 適用する Claude Code スキル

- `candidate_screen.md`：応募者の事前スクリーニング
- `interview_questions.md`：面接質問の設計
- `candidate_eval.md`：候補者評価の言語化（壁打ち）
- `onboarding_pack.md`：オンボーディング資料

### スモールビジネス特有の調整
- 人事制度がない場合のテンプレ提供
- 業務委託・パート採用への対応
- 退職予兆の検知（社員数少ないので簡易版）

## H. 意思決定（壁打ち）｜月3-10時間

### 含まれる業務
- H1. 経営判断の論点整理
- H2. 投資・出費の判断材料整理
- H3. 戦略変更の影響分析
- H4. リスクの洗い出し
- H5. 過去判断のレビュー

### 痛み
- 1人で判断するのが孤独
- 見落とし観点が怖い
- 後から振り返る時間がない

### 自動化の効果
**月3-10時間 → 質的に大幅向上**（時間削減より判断の質UP）

### 適用する Claude Code スキル
- `decision_logic.md`：論点整理の3パターン（賛否両論、影響先、過去比較）
- `strategy_review.md`：四半期ごとの戦略レビュー
- `risk_scenario.md`：リスクシナリオ生成
- `decision_log.md`：意思決定ログの蓄積

### スモールビジネス特有の調整
- 経営者個人の "判断癖" を学習
- 配偶者・パートナーへの説明文も自動生成
- 1か月単位での振り返り

## 業務カテゴリの選び方｜経営者タイプ別

### A. 一人代表（個人事業主・士業）
**最適な3業務**：
1. 顧客対応（C+D） — 最大の時間泥棒
2. 発信（E） — 集客への直結
3. 経理（F） — 月末の重圧解消

### B. 創業期スタートアップCEO
**最適な3業務**：
1. 朝の準備（A） — 経営判断の質直結
2. 会議運営（B） — 投資家・採用面接の準備
3. 採用（G） — 人材獲得は最優先

### C. 中堅安定経営型
**最適な3業務**：
1. 顧客・案件管理（C） — 属人化解消
2. 経理・事務（F） — 引き継ぎ可能化
3. 会議運営（B） — 経営会議の質UP

### D. 副業・複業経営者
**最適な3業務**：
1. 朝の準備（A） — 限られた時間の最大化
2. 顧客対応（D） — 各事業の同時管理
3. 発信（E） — 個人ブランディング

→ 最初の1か月でこれらを構築し、第2-3月で他のカテゴリへ拡張。

## 「やらない方が良い業務」も明示

経営者の業務の中には、**自動化を勧めない**ものもあります：

### ❌ 重要な対人交渉
- 採用最終面談、パートナーとの契約交渉
- 顧客との関係構築の根幹部分
- → 経営者本人が向き合うべき

### ❌ クリエイティブの最終決定
- ブランドメッセージ、ロゴ、最重要コピー
- "あなたの感性" が問われる部分
- → AIは下書きまで、最終判断は人

### ❌ 緊急時の対応
- クレーム対応、危機管理、人事の最終決断
- 機械的な対応では信頼を損なう
- → 経営者本人がスピードで対応

→ パッケージ初日にこれを明示することで、経営者が安心して導入できる。
