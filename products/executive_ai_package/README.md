# AI駆動経営 導入パッケージ

> スモールビジネスオーナー（1〜30名規模）の経営者向けに、Claude Code を中心とした
> "AIで経営業務を半分にする" 集中導入プログラムです。

---

## このパッケージは何か

### 一言で言うと
**「3か月で、経営者の雑務時間を半分にし、判断に専念できる体制を作る」** プロジェクトです。

### 対象
- 社員1〜30名の小規模事業の経営者
- 個人事業主・士業（弁護士・税理士・コンサル等）・コーチ
- 自分でほぼ全業務に関わっている経営者
- AIに興味あるが、自分の業務に組み込めていない方

### 対象でない
- 大企業（社員50名超） — 別途法人パックが必要
- AIをゴリゴリ使い倒している経営者
- "AIに任せれば全部解決" を期待している方

---

## ベースとなる考え方｜3つの柱

YouTube動画「AIで経営者の業務を半分にする」を参考に、スモールビジネス向けに調整した3つの柱です。

### 柱① 時間削減｜雑務を消す（最重要）
非生産的な業務（議事録、ニュース、下書き、転記）をAIに任せる。
**スモールビジネスでは、ここが圧倒的に大きい価値**。経営者が雑務に追われて経営判断ができていないケースが大半。

### 柱② 意思決定支援｜判断材料を整える
経営判断に必要な情報をAIが整理し、論点を提示する。
スモールビジネスでは特に「壁打ち相手がいない孤独」を解消する役割が大きい。

### 柱③ 見える化｜属人化を解消する
クライアント情報・案件・約束事をAIが参照可能な状態にする。
"頭の中だけで経営" している小規模ビジネスにとって、引き継ぎ可能な状態を作ることが価値。

> **大企業向け動画の "シグナル検知" は、200人規模ありき。**
> スモールビジネスでは経営者が直接見えるので、シグナル検知より "見える化" を優先します。

## 3か月での到達点

| 期間 | 主な達成 |
|---|---|
| 第1月 | 環境構築＋3〜4個の自動化スキル（議事録／朝のブリーフ／メール／コンテンツ） |
| 第2月 | クライアント・案件情報の構造化、業界モニタリング、意思決定の壁打ちフロー |
| 第3月 | 営業・採用・経理の半自動化、KPI簡易ダッシュボード、運用引き継ぎ |

→ **3か月終了時、経営者の雑務時間が月60-90時間減っている状態**を目標。

## なぜ "パッケージ" にするのか

### 月額顧問（AI顧問）との違い
- **顧問**：継続関係。"気軽に相談" の値段感
- **パッケージ**：プロジェクト。"3か月で結果を出す" の値段感

### スモールビジネスオーナーの心理
- 「終わりが見えない月額」より「3か月で完結」の方が決裁しやすい
- 「やってもらう」より「使える状態にしてもらう」を求める
- 結果が数字で見える方が経営判断として正当化しやすい

### アップセル動線
```
[2時間レッスン ¥30,000]
    ↓ "もっと体系的にやりたい"
[導入パッケージ ¥300,000]
    ↓ "終わったあとも伴走してほしい"
[AI顧問 月¥50,000]
    ↓ "社員にも展開したい"
[法人パック ¥600,000+]
```

## 動画から取り入れた重要ポイント

### ✅「夢からの逆算」
顧客の "こうありたい姿" を最初に深くヒアリングし、そこから自動化対象を選ぶ。
→ パッケージのStep 1で必ず実施。

### ✅「フィードバックループが8割」
ツール導入は2割、AIに対するフィードバック反復が8割。
→ 第1月はツール構築、第2-3月はフィードバック中心の設計。

### ✅「Slackボット中心」
朝のブリーフィング、シグナル検知をすべてSlackで完結。
→ スモールビジネス版では、Slack/メール/LINEから経営者の好みに合わせて選択可能に。

→ 詳細は各ファイル参照。
